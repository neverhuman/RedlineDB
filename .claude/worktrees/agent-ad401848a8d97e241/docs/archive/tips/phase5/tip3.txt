Below is how I would build **Phase 5 only**: `redlinedb_sql`, the SQL frontend and execution layer on top of your existing Rust kernel. I’m assuming the Phase 1 kernel is real and already has MVCC heap, row locks, WAL, CSN frontier, recovery, and transaction primitives. Phase 5 should **not** add a frontend global writer lock. SQLite’s own docs state that SQLite allows multiple readers but only one simultaneous writer, and WAL mode gives snapshot isolation by keeping readers on an older snapshot while the writer appends to the WAL. That is exactly the concurrency ceiling RedlineDB should avoid at the SQL layer. ([SQLite][1]) ([SQLite][2])

# Phase 5 goal

Build a pure-Rust SQL compiler and executor that turns:

```sql
SELECT name, age FROM users WHERE id = ?;
INSERT INTO users(id, name) VALUES (?, ?);
UPDATE users SET age = age + 1 WHERE id = ?;
DELETE FROM users WHERE created_at < ?;
BEGIN;
COMMIT;
ROLLBACK;
```

into direct calls against the RedlineDB storage kernel, with:

```text
SQL text
  -> parse
  -> internal AST
  -> bind names/types/parameters/schema
  -> logical plan
  -> physical plan
  -> prepared statement template
  -> per-execution statement state
  -> storage-kernel calls
  -> result rows
```

The main architectural rule: **prepare is allowed to allocate; step must be lean.** Prepared workloads are where embedded databases live or die.

SQLite treats a prepared statement as a compiled program: SQL text becomes a prepared object, values are bound, `step` is called one or more times, then the statement is reset/finalized. RedlineDB should mirror that lifecycle ergonomically in Rust now so the future C ABI is easy. ([SQLite][3])

# The big design decision

I would not build a SQLite VDBE clone in Phase 5.

Instead, I would build a **hybrid typed executor**:

1. **Relational operators** are represented as compact enum plan nodes, not boxed trait objects.
2. **Scalar expressions** are compiled into a tiny stack bytecode.
3. **Prepared statements** store immutable compiled templates.
4. **Statement executions** own mutable per-run state.
5. **Rows are evaluated zero-copy when possible**, with only result columns copied into statement-owned output memory.

This gives you:

```text
No global SQL mutex
No per-row column-name lookups
No per-row AST walking
No per-row heap allocation
No stringly typed planner state
No forced SQLite single-writer emulation
```

# Storage/kernel boundary

Do not let SQL reach into pages, WAL, latches, or buffer-pool internals. SQL talks to a narrow storage API.

Use generics internally if you want devirtualization, but a trait boundary is clearer:

```rust
pub trait EngineApi: Send + Sync + 'static {

    fn refresh_schema_snapshot(&self) -> Result<Arc<SchemaSnapshot>>;

    ) -> Result<RowId>;

    fn delete_row(
        &mut self,

        rowid: RowId,
        expected_version: RowVersion,
    ) -> Result<()>;

    fn insert_index_entry(
        &mut self,
        index: IndexId,

        rowid: RowId,
    ) -> Result<()>;

    fn delete_index_entry(
        &mut self,
        index: IndexId,
        key: EncodedKey,
        rowid: RowId,
    ) -> Result<()>;

    fn rollback_statement(&mut self, mark: StatementMark) -> Result<()>;
    fn commit_statement(&mut self, mark: StatementMark) -> Result<()>;

    fn next(&mut self) -> Result<Option<KernelRow>>;
}
```

`begin_statement` is important. Inside an explicit transaction, a failed `UPDATE` due to a constraint should roll back only that statement when possible, not the whole transaction. SQLite’s transaction docs describe that some errors attempt to undo the current statement while leaving earlier changes in the transaction intact, though severe cases can roll back the whole transaction. ([SQLite][1])

# Transaction/session model

SQLite automatically starts a transaction for commands that touch the database, and auto-started transactions are committed when the statement finishes. RedlineDB should mimic that ergonomically, while allowing more internal write concurrency than SQLite. ([SQLite][1])

Use:

```rust
#[derive(Debug, Clone, Copy)]
pub enum IsolationLevel {
    Snapshot,
    ReadCommitted,
}

#[derive(Debug, Clone, Copy)]
pub enum BeginMode {
    Deferred,
    Immediate,
    ReadOnly,
}

pub enum SessionTxn {
    None,

    Explicit {
        isolation: IsolationLevel,
        mode: BeginMode,
        txn: Box<dyn KernelTxn>,
        started_write: bool,
    },

    Auto {
        txn: Box<dyn KernelTxn>,
        read_only: bool,
    },
}

pub struct SessionState {
    txn: SessionTxn,
    autocommit: bool,
    default_isolation: IsolationLevel,
    busy_timeout: Duration,
    last_insert_rowid: Option<RowId>,
}
```

Rules:

```text
SELECT in autocommit:
  begin read txn on first step
  hold snapshot until SELECT is exhausted or reset
  release txn at Done/reset

INSERT/UPDATE/DELETE in autocommit:
  begin write txn
  execute whole statement
  commit before returning Done
  rollback on error

BEGIN DEFERRED:
  create explicit session state
  do not necessarily acquire write resources yet

BEGIN IMMEDIATE:
  begin write-capable transaction immediately
  but do not emulate SQLite's single global writer lock

COMMIT:
  commit explicit transaction

ROLLBACK:
  rollback explicit transaction
```

Critical RedlineDB divergence from SQLite:

```text
SQLite BEGIN IMMEDIATE prevents other writers.
RedlineDB BEGIN IMMEDIATE should only ensure this session has a valid write transaction.
It must not block disjoint writers at the SQL layer.
Actual conflicts are row/key/version conflicts in the kernel.
```

That preserves SQLite-like user ergonomics without importing SQLite’s write bottleneck.

```rust
impl Connection {
    pub fn prepare(self: &Arc<Self>, sql: &str) -> Result<Statement> {
        let schema = self.db.schema.load_full();
        let key = StmtCacheKey {
            sql_hash: fast_hash(sql.as_bytes()),
            schema_version: schema.version,
            flags: PrepareFlags::default(),
        };

        if let Some(template) = self.local_cache.get(&key) {
            return Ok(Statement::new(self.clone(), template));
        }

        if let Some(template) = self.db.stmt_cache.get(&key) {
            self.local_cache.insert(key, template.clone());
            return Ok(Statement::new(self.clone(), template));
        }

        let template = self.prepare_template(sql, schema)?;
        self.db.stmt_cache.insert(key, template.clone());
        self.local_cache.insert(key, template.clone());

        Ok(Statement::new(self.clone(), template))
    }
}
```

# Parser strategy

Use `sqlparser` only as a syntax frontend. Immediately convert its AST into your own compact AST. Never let third-party AST types leak into binder/planner/executor.

SQLite accepts semicolon-separated statement lists, but Phase 5 should compile exactly one statement per prepared statement unless you intentionally add a `prepare_many` helper. SQLite’s prepare APIs compile the first statement and expose the unused tail; RedlineDB’s Rust API can start stricter. ([SQLite][6]) ([SQLite][5])

```rust
pub fn parse_one(sql: &str) -> Result<RawStmt> {
    use sqlparser::dialect::GenericDialect;
    use sqlparser::parser::Parser;

    let dialect = GenericDialect {};
    let stmts = Parser::parse_sql(&dialect, sql)
        .map_err(|e| Error::parse(e.to_string()))?;

    match stmts.as_slice() {
        [] => Err(Error::EmptySql),
        [stmt] => convert_statement(stmt),
        _ => Err(Error::Unsupported {
            msg: "multiple statements per prepare are not supported yet".into(),
        }),
    }
}
```

# Parameter handling

SQLite supports `?`, `?NNN`, `:name`, `@name`, and `$name` host parameters, with 1-based parameter indexes. Unbound parameters evaluate as `NULL`. ([SQLite][7])

Build that now.

```rust
#[derive(Debug, Clone, Hash, Eq, PartialEq)]
pub enum ParamName {
    AnonymousOrdinal(usize), // ?
    Numbered(usize),         // ?NNN
    Named(Arc<str>),         // :x, @x, $x
}

#[derive(Debug, Clone)]
pub struct ParamLayout {
    // 1-based externally; 0-based internally.
    slots: Box<[ParamSlot]>,
    names: hashbrown::HashMap<Arc<str>, usize>,
}

#[derive(Debug, Clone)]
pub struct ParamSlot {
    pub public_index: usize,
    pub name: Option<Arc<str>>,
}

pub struct ParamBinder {
    next_index: usize,
    slots: Vec<ParamSlot>,
    names: hashbrown::HashMap<Arc<str>, usize>,
}

impl ParamBinder {
    pub fn bind_raw(&mut self, p: &RawParam) -> Result<ParamId> {
        match p {
            RawParam::Question => {
                let idx = self.next_index;
                self.next_index += 1;
                self.ensure_slot(idx, None)
            }
            RawParam::Numbered(n) => {
                if *n == 0 {
                    return Err(Error::InvalidParameter("?0 is not valid".into()));
                }
                self.next_index = self.next_index.max(n + 1);
                self.ensure_slot(*n, None)
            }
            RawParam::Named(name) => {
                if let Some(idx) = self.names.get(name) {
                    return Ok(ParamId(*idx));
                }

                let idx = self.next_index;
                self.next_index += 1;
                self.names.insert(name.clone(), idx);
                self.ensure_slot(idx, Some(name.clone()))
            }
        }
    }

    fn ensure_slot(&mut self, public_index: usize, name: Option<Arc<str>>) -> Result<ParamId> {
        let zero = public_index - 1;
        if zero >= MAX_PARAMS {
            return Err(Error::TooManyParameters);
        }

        while self.slots.len() <= zero {
            let idx = self.slots.len() + 1;
            self.slots.push(ParamSlot {
                public_index: idx,
                name: None,
            });
        }

        if let Some(name) = name {
            self.slots[zero].name = Some(name);
        }

        Ok(ParamId(zero as u16))
    }
}
```

Bindings should be compact:

```rust
pub struct Bindings {
    values: Box<[OwnedValue]>,
    set: Box<[bool]>,
}

impl Bindings {
    pub fn new(layout: &ParamLayout) -> Self {
        let n = layout.slots.len();
        Self {
            values: vec![OwnedValue::Null; n].into_boxed_slice(),
            set: vec![false; n].into_boxed_slice(),
        }
    }

    pub fn get(&self, id: ParamId) -> &OwnedValue {
        // Unset parameters are NULL.
        &self.values[id.0 as usize]
    }

    pub fn bind(&mut self, index_1_based: usize, value: OwnedValue) -> Result<()> {
        if index_1_based == 0 || index_1_based > self.values.len() {
            return Err(Error::ParameterOutOfRange(index_1_based));
        }

        let i = index_1_based - 1;
        self.values[i] = value;
        self.set[i] = true;
        Ok(())
    }
}
```

```rust
    False,
    Unknown,
}

impl<'a> ValueRef<'a> {
    pub fn sql_type(self) -> ValueType {
        match self {
            ValueRef::Null => ValueType::Null,
            ValueRef::Integer(_) => ValueType::Integer,
            ValueRef::Real(_) => ValueType::Real,
            ValueRef::Text(_) => ValueType::Text,
            ValueRef::Blob(_) => ValueType::Blob,
        }
    }

    pub fn truthy(self) -> Tri {
        match self {
            ValueRef::Null => Tri::Unknown,
            ValueRef::Integer(0) => Tri::False,
            ValueRef::Integer(_) => Tri::True,
            ValueRef::Real(v) if v == 0.0 => Tri::False,
            ValueRef::Real(_) => Tri::True,
            ValueRef::Text(s) => {
                // SQLite boolean contexts cast to numeric first.
                match parse_numeric_prefix(s) {
                    Numeric::Integer(0) => Tri::False,
                    Numeric::Real(v) if v == 0.0 => Tri::False,
                    Numeric::None => Tri::False,
                    _ => Tri::True,
                }
            }
            ValueRef::Blob(_) => Tri::False,
        }
    }
}
```

# Binder

The binder is where SQL becomes unambiguous.

Responsibilities:

```text
Resolve table names to TableId
Resolve column references to ColumnRef
Expand *
Check ambiguous columns
Check INSERT column arity
Fill omitted INSERT columns with DEFAULT or NULL
Validate NOT NULL where statically possible
Compile CHECK constraints
Resolve functions
Resolve parameters to ParamId
Assign output names
Infer expression affinity
Mark statement readonly or write
Collect referenced columns for projection pushdown
```

Pick index:

```rust
pub fn choose_access_path(
    table: &TableDef,
    predicate: Option<&BoundExpr>,
    schema: &SchemaSnapshot,
) -> AccessPath {
    let Some(pred) = predicate else {
        return AccessPath::TableScan;
    };

    let sargs = extract_sargable(pred);

    // Primary key equality wins.
    if let Some(pk) = table.primary_key {
        let idx = &schema.indexes[pk.as_usize()];
        if let Some(range) = build_index_range(idx, &sargs, Prefer::Equality) {
            return AccessPath::Index {
                index: pk,
                range,
                requires_recheck: true,
            };
        }
    }

    // Any usable secondary index.
    for idx_id in table.indexes.iter().copied() {
        let idx = &schema.indexes[idx_id.as_usize()];
        if let Some(range) = build_index_range(idx, &sargs, Prefer::EqualityThenRange) {
            return AccessPath::Index {
                index: idx_id,
                range,
                requires_recheck: true,
            };
        }
    }

    AccessPath::TableScan
}
```

Always keep a `post_filter` unless you can prove the index range fully covers the predicate. Stale MVCC-visible index entries must be heap-rechecked.

Evaluation stack:

```rust
pub struct EvalCtx<'a> {
    pub row: Option<RowView<'a>>,
    pub params: &'a Bindings,
    pub funcs: &'a FunctionRegistry,
    pub scratch: &'a mut EvalScratch,
}

pub struct EvalScratch {
    stack: smallvec::SmallVec<[OwnedValue; 16]>,
    temp_strings: Vec<u8>,
}

impl EvalScratch {
    pub fn clear(&mut self) {
        self.stack.clear();
        self.temp_strings.clear();
    }
}

impl ExprProgram {
    pub fn eval(&self, ctx: &mut EvalCtx<'_>) -> Result<OwnedValue> {
        ctx.scratch.clear();

        for op in self.ops.iter() {
            match *op {
                ExprOp::Const(i) => {
                    ctx.scratch.stack.push(self.consts[i as usize].clone());
                }

                ExprOp::Param(id) => {
                    ctx.scratch.stack.push(ctx.params.get(id).clone());
                }

                ExprOp::Column(slot) => {
                    let row = ctx.row.ok_or(Error::Internal("no row in expression"))?;
                    ctx.scratch.stack.push(row.get_owned(slot)?);
                }

                ExprOp::Binary(op) => {
                    let r = ctx.scratch.stack.pop().unwrap();
                    let l = ctx.scratch.stack.pop().unwrap();
                    let v = eval_binary(op, l.as_ref(), r.as_ref())?;
                    ctx.scratch.stack.push(v);
                }

                ExprOp::Unary(op) => {
                    let v = ctx.scratch.stack.pop().unwrap();
                    ctx.scratch.stack.push(eval_unary(op, v.as_ref())?);
                }

                ExprOp::Cast(aff) => {
                    let v = ctx.scratch.stack.pop().unwrap();
                    ctx.scratch.stack.push(apply_cast(v.as_ref(), aff)?);
                }

                ExprOp::Function { id, argc } => {
                    let base = ctx.scratch.stack.len() - argc as usize;
                    let args = &ctx.scratch.stack[base..];
                    let result = ctx.funcs.call(id, args)?;
                    ctx.scratch.stack.truncate(base);
                    ctx.scratch.stack.push(result);
                }

                _ => todo!("remaining expression op"),
            }
        }

        debug_assert_eq!(ctx.scratch.stack.len(), 1);
        Ok(ctx.scratch.stack.pop().unwrap())
    }
}
```

Compile `AND` and `OR` with short-circuit bytecode. SQLite’s expression docs describe operator precedence and special `NULL` behavior for `AND`, `OR`, `IS`, and `IS NOT`; do not fake these with plain Rust booleans. ([SQLite][8])

For a tree executor, each state stores child `PhysNodeId` and calls back into the execution arena:

```rust
pub struct ExecutionState {
    plan: Arc<PhysicalPlan>,
    states: Box<[ExecNodeState]>,
    root: PhysNodeId,
    arena: bumpalo::Bump,
    output: OutputRow,
    done: bool,
}

impl ExecutionState {
    pub fn next(&mut self, ctx: &mut ExecCtx<'_>) -> Result<ExecNext> {
        if self.done {
            return Ok(ExecNext::Done);
        }

        let next = self.next_node(self.root, ctx)?;

        if matches!(next, ExecNext::Done) {
            self.done = true;
        }

        Ok(next)
    }

    fn next_node(&mut self, id: PhysNodeId, ctx: &mut ExecCtx<'_>) -> Result<ExecNext> {
        match &mut self.states[id.as_usize()] {
            ExecNodeState::TableScan(s) => s.next(ctx),
            ExecNodeState::IndexScan(s) => s.next(ctx),
            ExecNodeState::RowIdLookup(s) => s.next(ctx),
            ExecNodeState::Filter(s) => {
                loop {
                    match self.next_node(s.input, ctx)? {
                        ExecNext::Row(row) => {
                            if s.matches(ctx, &row)? {
                                return Ok(ExecNext::Row(row));
                            }
                        }
                        ExecNext::Done => return Ok(ExecNext::Done),
                    }
                }
            }
            ExecNodeState::Project(s) => {
                match self.next_node(s.input, ctx)? {
                    ExecNext::Row(input) => {
                        let projected = s.project(ctx, &input)?;
                        Ok(ExecNext::Row(projected))
                    }
                    ExecNext::Done => Ok(ExecNext::Done),
                }
            }
            ExecNodeState::Limit(s) => {
                while s.skipped < s.offset {
                    match self.next_node(s.input, ctx)? {
                        ExecNext::Row(_) => s.skipped += 1,
                        ExecNext::Done => return Ok(ExecNext::Done),
                    }
                }

                if let Some(limit) = s.limit {
                    if s.emitted >= limit {
                        return Ok(ExecNext::Done);
                    }
                }

                match self.next_node(s.input, ctx)? {
                    ExecNext::Row(row) => {
                        s.emitted += 1;
                        Ok(ExecNext::Row(row))
                    }
                    ExecNext::Done => Ok(ExecNext::Done),
                }
            }
            _ => todo!("remaining nodes"),
        }
    }
}
```

For performance, after correctness is locked, specialize common plans:

```rust

    InsertSingleRow,
```

`SELECT ... WHERE pk = ?` should not run through a generic tree if it can compile to one direct `index_scan` or `get_by_rowid`.

# Statement stepping

```rust
impl Statement {
    pub fn step(&mut self) -> Result<Step> {
        self.ensure_fresh_template()?;

        if self.state.is_none() {
            let state = self.start_execution()?;
            self.state = Some(state);
        }

        let state = self.state.as_mut().unwrap();

        let mut session = self.conn.session.lock();
        let txn = session.ensure_txn_for(&self.template)?;

        let schema = self.conn.db.schema.load_full();
        let funcs = &schema.functions;

        let mut ctx = ExecCtx {
            txn,
            schema: &schema,
            params: &self.bindings,
            funcs,
            arena: &state.arena,
            eval: EvalScratch::default(),
            limits: &self.conn.db.options.runtime_limits,
        };

        match state.next(&mut ctx)? {
            ExecNext::Row(row) => {
                self.last_row = row;
                Ok(Step::Row)
            }

            ExecNext::Done => {
                let changed = state.changed_rows();
                session.finish_statement(&self.template, true)?;
                self.state = None;
                self.last_row.values.clear();
                self.conn.set_last_changes(changed);
                Ok(Step::Done)
            }
        }
    }

    pub fn reset(&mut self) -> Result<()> {
        if self.state.is_some() {
            let mut session = self.conn.session.lock();
            session.finish_statement(&self.template, false)?;
        }

        self.state = None;
        self.last_row.values.clear();
        Ok(())
    }
}
```

`finish_statement(success = false)` rolls back an autocommit write or releases an autocommit read. In an explicit transaction, it rolls back to the statement mark if needed.

```rust
pub struct InsertValuesState {
    plan: Arc<InsertValuesPlan>,
    next_row: usize,
    changed: usize,
    mark: Option<StatementMark>,
}

impl InsertValuesState {
    pub fn next(&mut self, ctx: &mut ExecCtx<'_>) -> Result<ExecNext> {
        if self.mark.is_none() {
            self.mark = Some(ctx.txn.begin_statement()?);
        }

        while self.next_row < self.plan.rows.len() {
            let exprs = &self.plan.rows[self.next_row];
            self.next_row += 1;

            let mut values = build_default_row(ctx.schema, self.plan.table)?;

            for (target_col, expr) in self.plan.column_map.iter().zip(exprs.iter()) {
                let v = expr.eval(&mut EvalCtx {
                    row: None,
                    params: ctx.params,
                    funcs: ctx.funcs,
                    scratch: &mut ctx.eval,
                })?;

                assign_column(
                    ctx.schema,
                    self.plan.table,
                    &mut values,
                    *target_col,
                    v,
                )?;
            }

            enforce_not_nulls(ctx.schema, self.plan.table, &values)?;
            enforce_checks(ctx, self.plan.table, &values)?;

            let encoded = encode_sql_row(ctx.schema, self.plan.table, &values)?;
            let rowid = ctx.txn.insert_row(self.plan.table.into_relation(), encoded)?;

            for idx in self.plan.indexes.iter() {
                let key = build_index_key_from_values(ctx.schema, idx.index, &values)?;
                ctx.txn.insert_index_entry(idx.index, key, rowid)?;
            }

            self.changed += 1;
        }

        if let Some(mark) = self.mark.take() {
            ctx.txn.commit_statement(mark)?;
        }

        Ok(ExecNext::Done)
    }
}
```

Important:

```text
All row validation happens before publishing index entries when possible.
Unique index conflicts are checked by kernel key locks.
Statement mark rolls back partial multi-row INSERT on error.
Autocommit commit happens outside the node when statement finishes.
```

# UPDATE implementation

Avoid the Halloween problem.

Bad:

```text
scan index on age
update age = age + 1
same row appears again
```

Safe Phase 5 approach:

```text
1. Find candidate rowids under snapshot.
2. Process in bounded chunks.
3. For each rowid:
   - fetch current visible row
   - recheck predicate
   - lock/update using expected row version
   - update secondary indexes
```

Chunked rowid collection keeps memory bounded.

Execution skeleton:

```rust
impl UpdateRowsState {
    pub fn next(&mut self, ctx: &mut ExecCtx<'_>) -> Result<ExecNext> {
        if self.mark.is_none() {
            self.mark = Some(ctx.txn.begin_statement()?);
        }

        loop {
            if self.candidates.is_empty() && !self.scan_done {
                self.fill_candidate_chunk(ctx)?;
            }

            let Some(candidate) = self.candidates.pop() else {
                if let Some(mark) = self.mark.take() {
                    ctx.txn.commit_statement(mark)?;
                }
                return Ok(ExecNext::Done);
            };

            let Some(old_row) = ctx.txn.get_by_rowid(
                self.plan.table.into_relation(),
                candidate.rowid,
                ColumnMask::all(),
            )? else {
                continue;
            };

            let old_view = decode_row(ctx.schema, self.plan.table, &old_row)?;

            if let Some(pred) = &self.plan.predicate {
                let keep = pred.eval(&mut EvalCtx {
                    row: Some(old_view.as_ref()),
                    params: ctx.params,
                    funcs: ctx.funcs,
                    scratch: &mut ctx.eval,
                })?;

                if keep.as_ref().truthy() != Tri::True {
                    continue;
                }
            }

            let mut new_values = old_view.to_owned_values();

            for assign in self.plan.assignments.iter() {
                let v = assign.expr.eval(&mut EvalCtx {
                    row: Some(old_view.as_ref()),
                    params: ctx.params,
                    funcs: ctx.funcs,
                    scratch: &mut ctx.eval,
                })?;

                assign_column(
                    ctx.schema,
                    self.plan.table,
                    &mut new_values,
                    assign.column,
                    v,
                )?;
            }

            enforce_not_nulls(ctx.schema, self.plan.table, &new_values)?;
            enforce_checks(ctx, self.plan.table, &new_values)?;

            let old_index_keys = build_all_index_keys(ctx.schema, self.plan.table, &old_view)?;
            let new_index_keys = build_all_index_keys_from_values(
                ctx.schema,
                self.plan.table,
                &new_values,
            )?;

            let encoded = encode_sql_row(ctx.schema, self.plan.table, &new_values)?;

            let new_rowid = ctx.txn.update_row(
                self.plan.table.into_relation(),
                candidate.rowid,
                old_row.version,
                encoded,
            )?;

            maintain_indexes_for_update(
                ctx.txn,
                &self.plan.indexes,
                candidate.rowid,
                new_rowid,
                &old_index_keys,
                &new_index_keys,
            )?;

            self.changed += 1;
        }
    }
}
```

# DDL execution

Phase 5 DDL should be thin. The catalog/storage layer owns transactional DDL. SQL frontend parses and validates.

```rust
pub enum DdlOp {
    CreateTable(CreateTableOp),
    DropTable(DropTableOp),
    CreateIndex(CreateIndexOp),
    DropIndex(DropIndexOp),
}

pub struct DdlState {
    op: DdlOp,
    done: bool,
}

impl DdlState {
    pub fn next(&mut self, ctx: &mut ExecCtx<'_>) -> Result<ExecNext> {
        if self.done {
            return Ok(ExecNext::Done);
        }

        match &self.op {
            DdlOp::CreateTable(op) => {
                ctx.txn.catalog_create_table(op.clone())?;
            }
            DdlOp::CreateIndex(op) => {
                ctx.txn.catalog_create_index(op.clone())?;
                // Optionally build index immediately by scanning table in same txn.
            }
            DdlOp::DropTable(op) => {
                ctx.txn.catalog_drop_table(op.table)?;
            }
            DdlOp::DropIndex(op) => {
                ctx.txn.catalog_drop_index(op.index)?;
            }
        }

        self.done = true;
        Ok(ExecNext::Done)
    }
}
```

```rust
pub fn enforce_not_nulls(
    schema: &SchemaSnapshot,
    table: TableId,
    row: &[OwnedValue],
) -> Result<()> {
    for col in schema.table(table).columns.iter() {
        if !col.nullable && matches!(row[col.ordinal], OwnedValue::Null) {
            return Err(Error::ConstraintViolation(ConstraintKind::NotNull {
                table,
                column: col.id,
            }));
        }
    }
    Ok(())
}

pub fn enforce_checks(
    ctx: &mut ExecCtx<'_>,
    table: TableId,
    row: &[OwnedValue],
) -> Result<()> {
    let table_def = ctx.schema.table(table);

    let row_view = RowView::from_owned(table, row);

    for col in table_def.columns.iter() {
        if let Some(check) = &col.check {
            let v = check.eval(&mut EvalCtx {
                row: Some(row_view.as_ref()),
                params: ctx.params,
                funcs: ctx.funcs,
                scratch: &mut ctx.eval,
            })?;

            // SQLite CHECK passes if expression is true or NULL; fails only on false.
            if v.as_ref().truthy() == Tri::False {
                return Err(Error::ConstraintViolation(ConstraintKind::Check));
            }
        }
    }

    Ok(())
}
```

```rust
    Binary,
    NoCase,
    RTrim,

pub fn compare_text(a: &str, b: &str, coll: CollationId) -> Ordering {
    match coll {
        CollationId::Binary => a.as_bytes().cmp(b.as_bytes()),
        CollationId::NoCase => ascii_nocase_cmp(a.as_bytes(), b.as_bytes()),
        CollationId::RTrim => rtrim_spaces(a.as_bytes()).cmp(rtrim_spaces(b.as_bytes())),
```

Do not implement full Unicode case folding in Phase 5 unless you are willing to carry the cost and compatibility burden. # Memory management

Use arenas for prepare/execution scratch, but do not share one arena across threads. `bumpalo::Bump` allocates chunks as needed, and its docs note that `Bump` is not `Sync`; it also supports allocation limits. ([Docs.rs][9]) ([Docs.rs][10])

Memory rules:

```text
PreparedTemplate:
  Arc-owned, immutable, cacheable

ExecutionState:
  per statement execution
  owns Bump arena
  dropped/reset after statement completion

EvalScratch:
  reused per row
  no heap allocation for common arithmetic/comparison

OutputRow:
  stores only current result row
  valid until next step/reset

Sort/hash/materialization:
  explicitly budgeted
  spills when over budget
```

# Threading model

Phase 5 must not ruin the kernel’s concurrency.

Use this threading model:

```text
Database:
  Arc, Send + Sync
  owns engine, schema snapshot, shared caches

Connection:
  Arc, Send
  session txn state behind a small Mutex
  no long lock during IO/fsync

Statement:
  Send, not Sync
  stepped by &mut self

Schema:
  immutable Arc snapshot
  DDL swaps snapshot after commit

Statement cache:
  sharded locks
  no single global compile/cache lock except rare DDL schema rebuild

Execution:
  caller thread executes synchronously
  no async runtime
  no Tokio
  no hidden worker pool for normal SQL
```

Do **not** hold the session mutex while doing long storage scans if your transaction object can be temporarily borrowed safely. A better pattern is:

```rust
// Session lock only to acquire/attach txn.
let txn_handle = session.checkout_txn_for_statement(...)?;
// unlock session
// execute statement using txn_handle
// lock session briefly to finish/commit/rollback
```

If the current kernel requires `&mut KernelTxn` stored inside `SessionState`, keep the lock but do not let unrelated connections share that lock. The lock is per connection/session, not global.

# Fast paths that matter immediately

## 1. `SELECT ... WHERE rowid = ?`

Compile to direct lookup.

```rust
pub struct RowIdLookupPlan {
    pub table: TableId,
    pub rowid_expr: ExprProgram,
    pub projection: Box<[ExprProgram]>,
    pub post_filter: Option<ExprProgram>,
}

pub struct RowIdLookupState {
    plan: Arc<RowIdLookupPlan>,
    done: bool,
}

impl RowIdLookupState {
    pub fn next(&mut self, ctx: &mut ExecCtx<'_>) -> Result<ExecNext> {
        if self.done {
            return Ok(ExecNext::Done);
        }

        self.done = true;

        let rowid_val = self.plan.rowid_expr.eval(&mut EvalCtx {
            row: None,
            params: ctx.params,
            funcs: ctx.funcs,
            scratch: &mut ctx.eval,
        })?;

        let rowid = coerce_rowid(rowid_val.as_ref())?;

        let Some(krow) = ctx.txn.get_by_rowid(
            self.plan.table.into_relation(),
            rowid,
            ColumnMask::all(),
        )? else {
            return Ok(ExecNext::Done);
        };

        let row = decode_row(ctx.schema, self.plan.table, &krow)?;

        if let Some(pred) = &self.plan.post_filter {
            let keep = pred.eval(&mut EvalCtx {
                row: Some(row.as_ref()),
                params: ctx.params,
                funcs: ctx.funcs,
                scratch: &mut ctx.eval,
            })?;

            if keep.as_ref().truthy() != Tri::True {
                return Ok(ExecNext::Done);
            }
        }

        let out = project_row(ctx, row.as_ref(), &self.plan.projection)?;
        Ok(ExecNext::Row(out))
    }
}
```

```rust
impl Connection {
    fn prepare_template(
        self: &Arc<Self>,
        sql: &str,
        schema: Arc<SchemaSnapshot>,
    ) -> Result<Arc<PreparedTemplate>> {
        let raw = parser::parse_one(sql)?;

        let mut bind_ctx = BindCtx::new(schema.clone());
        let bound = binder::bind_stmt(&mut bind_ctx, raw)?;

        let param_layout = bind_ctx.finish_params();

        let template = match bound {
            BoundStmt::Select(sel) => {
                let logical = planner::logical_select(sel)?;
                let physical = planner::physical_plan(&schema, logical)?;

                PreparedTemplate {
                    sql: Arc::from(sql),
                    normalized_sql_hash: fast_hash(sql.as_bytes()),
                    schema_version: schema.version,
                    param_layout,
                    output: physical.output.clone(),
                    readonly: true,
                    kind: PreparedKind::Query {
                        plan: Arc::new(physical),
                    },
                }
            }

            BoundStmt::Insert(ins) => {
                let plan = planner::plan_insert(&schema, ins)?;

                PreparedTemplate {
                    sql: Arc::from(sql),
                    normalized_sql_hash: fast_hash(sql.as_bytes()),
                    schema_version: schema.version,
                    param_layout,
                    output: Arc::from([]),
                    readonly: false,
                    kind: PreparedKind::Insert {
                        plan: Arc::new(plan),
                    },
                }
            }

            BoundStmt::Update(upd) => {
                let plan = planner::plan_update(&schema, upd)?;

                PreparedTemplate {
                    sql: Arc::from(sql),
                    normalized_sql_hash: fast_hash(sql.as_bytes()),
                    schema_version: schema.version,
                    param_layout,
                    output: Arc::from([]),
                    readonly: false,
                    kind: PreparedKind::Update {
                        plan: Arc::new(plan),
                    },
                }
            }

            BoundStmt::Delete(del) => {
                let plan = planner::plan_delete(&schema, del)?;

                PreparedTemplate {
                    sql: Arc::from(sql),
                    normalized_sql_hash: fast_hash(sql.as_bytes()),
                    schema_version: schema.version,
                    param_layout,
                    output: Arc::from([]),
                    readonly: false,
                    kind: PreparedKind::Delete {
                        plan: Arc::new(plan),
                    },
                }
            }

            BoundStmt::Ddl(op) => PreparedTemplate {
                sql: Arc::from(sql),
                normalized_sql_hash: fast_hash(sql.as_bytes()),
                schema_version: schema.version,
                param_layout,
                output: Arc::from([]),
                readonly: false,
                kind: PreparedKind::Ddl { op: Arc::new(op) },
            },

            BoundStmt::Txn(op) => PreparedTemplate {
                sql: Arc::from(sql),
                normalized_sql_hash: fast_hash(sql.as_bytes()),
                schema_version: schema.version,
                param_layout,
                output: Arc::from([]),
                readonly: false,
                kind: PreparedKind::Txn { op },
            },
        };

        Ok(Arc::new(template))
```

```rust
impl SessionState {
    pub fn ensure_txn_for<'a>(
        &'a mut self,
        db: &Database,
        template: &PreparedTemplate,
    ) -> Result<&'a mut dyn KernelTxn> {
        match &mut self.txn {
            SessionTxn::Explicit { txn, .. } => Ok(txn.as_mut()),

            SessionTxn::Auto { txn, .. } => Ok(txn.as_mut()),

            SessionTxn::None => {
                let mode = if template.readonly {
                    KernelTxnMode::ReadOnly
                } else {
                    KernelTxnMode::ReadWrite
                };

                let txn = db.engine.begin_txn(mode, self.default_isolation)?;

                self.txn = SessionTxn::Auto {
                    txn,
                    read_only: template.readonly,
                };

                match &mut self.txn {
                    SessionTxn::Auto { txn, .. } => Ok(txn.as_mut()),
                    _ => unreachable!(),
                }
            }
        }
    }

    pub fn finish_statement(
        &mut self,
        db: &Database,
        template: &PreparedTemplate,
        success: bool,
    ) -> Result<()> {
        match std::mem::replace(&mut self.txn, SessionTxn::None) {
            SessionTxn::Auto { txn, .. } => {
                if success {
                    let info = txn.commit()?;

                    if template_modifies_schema(template) {
                        let fresh = db.engine.refresh_schema_snapshot()?;
                        db.schema.store(fresh);
                    }

                    self.last_insert_rowid = info.last_insert_rowid;
                } else {
                    txn.rollback()?;
                }
            }

            explicit @ SessionTxn::Explicit { .. } => {
                self.txn = explicit;
            }

            SessionTxn::None => {}
        }

        Ok(())
    }
}
```

# The correctness invariants Phase 5 must enforce

```text
1. SQL never sees uncommitted changes from other sessions.

2. A prepared SELECT in snapshot isolation sees one stable snapshot until reset/done.

3. Read committed creates a fresh statement snapshot per statement.

4. Autocommit write statements are atomic.

5. Explicit transaction write statements have statement-level rollback marks.

6. Failed constraint checks do not leave partial index entries.

7. Failed multi-row INSERT rolls back all rows from that statement.

8. UPDATE/DELETE recheck predicates after row lookup/lock.

9. Index scans heap-recheck MVCC visibility.

10. Prepared statements invalidate on schema version mismatch.

11. DDL commits atomically with catalog changes.

12. No frontend global writer lock exists.

13. `step` does not allocate per row for simple scans/predicates.

14. `ORDER BY` and materialization obey memory budgets.

15. Unsupported SQL returns an explicit unsupported-feature error.
```

# The performance rules I would enforce in code review

```rust
let db = Arc::new(Database::open("redline.db", DbOptions::default())?);
let conn = Arc::new(db.connect());

conn.execute("CREATE TABLE users(id INTEGER PRIMARY KEY, name TEXT NOT NULL, age INTEGER)")?;

let mut ins = conn.prepare("INSERT INTO users(id, name, age) VALUES (?, ?, ?)")?;
for i in 0..1000 {
    ins.bind_i64(1, i)?;
    ins.bind_text(2, format!("user-{i}"))?;
    ins.bind_i64(3, 20 + (i % 10))?;
    assert_eq!(ins.step()?, Step::Done);
    ins.reset()?;
}

let mut q = conn.prepare("SELECT name, age FROM users WHERE id = ?")?;
q.bind_i64(1, 42)?;

match q.step()? {
    Step::Row => {
        assert_eq!(q.column_text(0)?, "user-42");
        assert_eq!(q.column_i64(1)?, 22);
    }
    Step::Done => panic!("missing row"),
}
```
