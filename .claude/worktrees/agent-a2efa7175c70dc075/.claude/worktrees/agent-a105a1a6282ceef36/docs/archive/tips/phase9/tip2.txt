Below is how I would build **Phase 9: Benchmark Certification and SQLite Head-to-Head** as a production-grade Rust benchmark, verification, crash, and reporting system. The point is not just to “run some benchmarks.” The point is to make RedlineDB’s performance claims **reproducible, adversarially fair, hard to fool, and useful for engineering decisions**.

The benchmark harness itself should be **100% Rust**. The SQLite comparison adapter necessarily links to SQLite through Rust FFI or `libsqlite3-sys` because SQLite is the baseline being measured; that should stay isolated in `redlinedb_bench::engines::sqlite` and must not leak SQLite internals into RedlineDB.

SQLite-specific constraints matter a lot. In WAL mode, SQLite lets readers and one writer overlap, but “there can only be one writer at a time,” which is exactly the ceiling RedlineDB should beat on disjoint concurrent-writer workloads. SQLite WAL checkpointing also affects latency and WAL size: long readers can stop checkpoint progress, default auto-checkpointing can make occasional commits slower, and `synchronous=FULL` versus `NORMAL` changes fsync and durability behavior. These are not details; they define the fairness rules for Phase 9. ([SQLite][1])

---

# Phase 9 objective

Phase 9 should produce this:

```text
redlinedb_bench/
  1. A deterministic benchmark runner.
  2. SQLite and RedlineDB adapters.
  3. A workload suite covering OLTP, reads, writes, ranges, joins, checkpoint pressure, recovery, and memory ceilings.
  4. A correctness/compatibility runner that compares supported SQL against SQLite.
  5. A crash/recovery certification harness.
  6. A metrics system capturing latency distributions, throughput, WAL bytes/op, data bytes/op, RSS, checkpoint stalls, recovery time, and correctness checksums.
  7. A report generator with honest release gates.
```

The real deliverable is not “RedlineDB is faster.” The real deliverable is:

```text
For workload W, durability profile D, memory profile M, thread count T,
on machine H, RedlineDB version R and SQLite version S:

  - produced identical supported SQL results,
  - preserved acknowledged commits under the relevant crash model,
  - stayed within memory bounds,
  - had measured latency/throughput/database-size/recovery-time metrics,
  - and passed or failed an explicit release gate.
```

# The core design rule

Do not benchmark implementation details. Benchmark **user-visible database behavior**.

That means the harness should measure:

```text
prepare + bind + step + reset
transaction begin + commit
actual reads/writes
actual checkpoint effects
actual recovery after unclean shutdown
actual memory usage
actual WAL/database file growth
actual contention under N sessions
```

It should avoid:

```text
calling RedlineDB kernel APIs when SQLite is using SQL;
letting SQLite use default auto-checkpointing while RedlineDB uses a tuned background checkpoint worker;
using different durability promises;
comparing RedlineDB cached in-process memory against SQLite cold OS-cache reads;
ignoring SQLITE_BUSY;
claiming wins on unsupported SQL;
claiming NORMAL-mode numbers as strict durable numbers.
```

SQLite exposes `sqlite3_db_status()` and related status counters for cache/memory/cache-write information, so the SQLite adapter should collect those in addition to process-level metrics. ([SQLite][2])

# Durability profiles

Do not compare a strict RedlineDB commit path against SQLite `synchronous=NORMAL`, and do not compare RedlineDB relaxed group commit against SQLite `synchronous=FULL`.

Define explicit profiles:

```rust
#[derive(Debug, Clone, Copy, serde::Serialize, serde::Deserialize)]
pub enum DurabilityMode {
    /// Commit is acknowledged only after WAL/data durability required for power-loss survival.
    StrictFull,

    /// Process-crash safe, but may lose recent commits on OS crash/power loss depending on engine.
    Normal,

    /// No fsync durability. Dev/perf ceiling only. Never used for replacement claims.
    Unsafe,
}
```

Mapping:

```text
StrictFull:
  SQLite:
    PRAGMA journal_mode=WAL;
    PRAGMA synchronous=FULL;
    PRAGMA wal_autocheckpoint=0;
  RedlineDB:
    commit ack only after durable WAL fsync/group fsync satisfying strict mode;
    dirty data never ahead of durable WAL;
    checkpoint fsync rules enabled.

Normal:
  SQLite:
    PRAGMA journal_mode=WAL;
    PRAGMA synchronous=NORMAL;
    PRAGMA wal_autocheckpoint=0;
  RedlineDB:
    no per-commit fsync, but safe against process crash;
    fsync during checkpoint or configured group interval;
    clearly labelled as not strict power-loss durable.

Unsafe:
  SQLite:
    PRAGMA journal_mode=WAL;
    PRAGMA synchronous=OFF;
    PRAGMA wal_autocheckpoint=0;
  RedlineDB:
    no fsync;
    used only to find CPU/lock/encoding ceilings.
```

SQLite’s docs explicitly state that in WAL mode `synchronous=FULL` adds a WAL sync after every transaction commit, while `NORMAL` avoids syncs during most transactions and may lose durability across power loss even though WAL remains consistent. ([SQLite][5])

# SQLite configuration

For every SQLite connection:

```sql
PRAGMA journal_mode = WAL;
PRAGMA synchronous = FULL | NORMAL | OFF;
PRAGMA wal_autocheckpoint = 0;
PRAGMA busy_timeout = 30000;
PRAGMA temp_store = MEMORY;
PRAGMA mmap_size = 0;
PRAGMA foreign_keys = ON;
```

Why:

```text
journal_mode=WAL:
  Required baseline.

synchronous:
  Matched durability profile.

wal_autocheckpoint=0:
  We control checkpoint timing explicitly.
  Otherwise SQLite may checkpoint inside a COMMIT once the WAL reaches its threshold,
  causing unpredictable commit latency.

busy_timeout:
  SQLite’s second writer will wait behind the first writer.
  Waiting time must count as latency.
  SQLITE_BUSY after the timeout is a benchmark failure or a recorded failed op,
  not something to ignore.

temp_store=MEMORY:
  Avoids unrelated temp-file behavior unless the workload explicitly tests spilling.

mmap_size=0:
  Avoids giving SQLite mmap advantages unless RedlineDB also has an mmap profile.

foreign_keys=ON:
  Use real SQL semantics where relevant.
```

SQLite documents that a busy timeout sleeps/retries until the configured time has accumulated, after which `sqlite3_step()` returns `SQLITE_BUSY`; the benchmark should count that outcome explicitly. ([SQLite][6])

For thread mode, use one SQLite connection per worker thread and open each connection with `SQLITE_OPEN_NOMUTEX` only if every connection is used by one thread at a time. SQLite documents serialized mode as the default and says `SQLITE_OPEN_NOMUTEX` creates a multi-thread-mode connection where the application must not use the same connection concurrently from multiple threads. ([SQLite][7])

# Checkpoint profiles

Do not hide checkpoint costs. Run three profiles:

```rust
#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub enum CheckpointPolicy {
    /// No checkpoint during timed section. Measures append path and WAL growth.
    NoneDuringRun,

    /// Separate checkpointer thread tries PASSIVE checkpoints based on WAL bytes or time.
    Background {
        every_ms: u64,
        wal_bytes_threshold: u64,
    },

    /// Aggressive checkpoint pressure. Intended to expose stalls and long-reader behavior.
    Pressure {
        every_ms: u64,
        mode: CheckpointMode,
    },
}

#[derive(Debug, Clone, Copy, serde::Serialize, serde::Deserialize)]
pub enum CheckpointMode {
    Passive,
    Full,
    Restart,
    Truncate,
}
```

SQLite checkpoint behavior is a major source of latency differences. `PASSIVE` may leave work unfinished if readers or writers are active; `FULL`, `RESTART`, and `TRUNCATE` can block more aggressively, with `TRUNCATE` also truncating the WAL on success. ([SQLite][8])

The default release claim should use:

```text
StrictFull + Background checkpoint
Normal + Background checkpoint
Unsafe + No checkpoint during run, clearly labelled
```

The stress suite should include:

```text
StrictFull + Pressure checkpoint
Normal + Pressure checkpoint
long reader + background checkpoint
long reader + truncate checkpoint
```

## Thread/session matrix

```text
connections / worker threads:
  1, 2, 4, 8, 16, 32, 64

writer fractions:
  0%, 5%, 20%, 50%, 100%

key distributions:
  uniform
  zipf_hotspot
  disjoint_per_writer

record sizes:
  16 bytes
  100 bytes
  1 KiB
  8 KiB

database sizes:
  small: fits in cache
  medium: exceeds configured DB page cache but fits OS page cache
  large: exceeds RAM, optional dedicated machine only
```

The most important “RedlineDB should beat SQLite” workload is:

```text
concurrent_disjoint_writers
  N writer sessions
  no logical row conflicts
  fixed-size update or insert transactions
  strict durability and normal durability separately
  background checkpoint enabled
```

SQLite should hit its single-writer ceiling there. RedlineDB should scale until WAL, CPU, row-lock, or device limits.

The most important “RedlineDB is a serious replacement” workloads are:

```text
single-thread point read
single-thread insert
single-thread update
single-thread range scan
batched insert
indexed lookup
```

If RedlineDB loses badly on these, the concurrent writer win is not enough.

# Engine abstraction

The key is to make dispatch static inside the hot loop. Do not make every operation go through a boxed trait object if you can avoid it.

```rust
// src/engines/traits.rs

use crate::config::{BenchConfig, CheckpointMode, DurabilityMode};
use crate::metrics::{CheckpointStats, EngineStats};
use anyhow::Result;
use std::path::Path;

pub trait BenchEngine: Sync + 'static {
    type Conn<'a>: KvOps
    where
        Self: 'a;

    fn name() -> &'static str;

    fn create_database(path: &Path, cfg: &BenchConfig) -> Result<()>;

    fn open_worker<'a>(
        worker_id: usize,
        path: &'a Path,
        cfg: &'a BenchConfig,
    ) -> Result<Self::Conn<'a>>;

    fn checkpoint(path: &Path, cfg: &BenchConfig, mode: CheckpointMode)
        -> Result<CheckpointStats>;

    fn collect_engine_stats(path: &Path, cfg: &BenchConfig) -> Result<EngineStats>;

    fn integrity_check(path: &Path, cfg: &BenchConfig) -> Result<String>;
}

pub trait KvOps {
    fn setup_schema(&mut self) -> Result<()>;
    fn prepare_kv_statements(&mut self) -> Result<()>;

    fn begin(&mut self) -> Result<()>;
    fn commit(&mut self) -> Result<()>;
    fn rollback(&mut self) -> Result<()>;

    fn insert_kv(&mut self, key: i64, value: &[u8], n: i64) -> Result<()>;
    fn update_kv(&mut self, key: i64, value: &[u8]) -> Result<u64>;
    fn delete_kv(&mut self, key: i64) -> Result<u64>;

    /// Returns checksum contribution, not the raw value, to avoid allocation.
    fn point_read_kv(&mut self, key: i64) -> Result<Option<u64>>;

    /// Returns number of rows and checksum.
    fn range_scan_kv(&mut self, start_key: i64, limit: u64) -> Result<(u64, u64)>;

    fn indexed_lookup_n(&mut self, n: i64, limit: u64) -> Result<(u64, u64)>;

    fn row_count(&mut self, table: &str) -> Result<u64>;
    fn table_checksum(&mut self, table: &str) -> Result<u64>;
}
```

This abstraction gives you:

```text
same workload logic;
engine-specific optimized prepared statements;
no dynamic dispatch in the inner loop if run as run::<SqliteEngine, Workload>();
easy NullEngine harness-overhead measurement.
```

```rust
// src/metrics.rs

use hdrhistogram::Histogram;
use serde::{Deserialize, Serialize};
use std::time::{Duration, Instant};

#[derive(Debug)]
pub struct WorkerMetrics {
    pub ops_attempted: u64,
    pub ops_completed: u64,
    pub ops_failed: u64,
    pub checksum: u64,
    pub latency: Histogram<u64>,
}

impl WorkerMetrics {
    pub fn new() -> Self {
        Self {
            ops_attempted: 0,
            ops_completed: 0,
            ops_failed: 0,
            checksum: 0,
            latency: Histogram::new_with_bounds(1, 3_600_000_000_000, 3)
                .expect("valid histogram bounds"),
        }
    }

    #[inline]
    pub fn record_success(&mut self, elapsed: Duration, checksum_delta: u64) {
        self.ops_attempted += 1;
        self.ops_completed += 1;
        self.checksum ^= checksum_delta.rotate_left((self.ops_completed % 63) as u32);
        let ns = elapsed.as_nanos().min(u64::MAX as u128) as u64;
        let _ = self.latency.record(ns.max(1));
    }

    #[inline]
    pub fn record_failure(&mut self, elapsed: Duration) {
        self.ops_attempted += 1;
        self.ops_failed += 1;
        let ns = elapsed.as_nanos().min(u64::MAX as u128) as u64;
        let _ = self.latency.record(ns.max(1));
    }
}

#[derive(Debug, Clone, Serialize, Deserialize)]

    pub min_ns: u64,

    pub p90_ns: u64,
```

# Fast deterministic random input

Use a splittable deterministic seed per worker.

```rust
// src/random.rs

use rand::{Rng, SeedableRng};
use rand_chacha::ChaCha8Rng;

pub struct WorkerRng {
    rng: ChaCha8Rng,
}

impl WorkerRng {
    pub fn new(global_seed: u64, worker_id: usize) -> Self {
        let seed = splitmix64(global_seed ^ ((worker_id as u64).wrapping_mul(0x9e3779b97f4a7c15)));
        Self {
            rng: ChaCha8Rng::seed_from_u64(seed),
        }
    }

    #[inline]
    pub fn uniform_key(&mut self, max_key: u64) -> i64 {
        self.rng.random_range(1..=max_key) as i64
    }

    #[inline]
    pub fn disjoint_key(&mut self, worker_id: usize, workers: usize, max_key: u64) -> i64 {
        let per_worker = max_key / workers as u64;
        let start = worker_id as u64 * per_worker + 1;
        let end = if worker_id + 1 == workers {
            max_key
        } else {
            start + per_worker - 1
        };
        self.rng.random_range(start..=end) as i64
    }

    #[inline]
    pub fn bool_ratio(&mut self, numerator: u32, denominator: u32) -> bool {
        self.rng.random_range(0..denominator) < numerator
    }
}

#[inline]
pub fn splitmix64(mut x: u64) -> u64 {
    x = x.wrapping_add(0x9e3779b97f4a7c15);
    let mut z = x;
    z = (z ^ (z >> 30)).wrapping_mul(0xbf58476d1ce4e5b9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94d049bb133111eb);
    z ^ (z >> 31)
}
```

# Payload and checksum

```rust
// src/checksum.rs

#[inline]
pub fn make_payload(seed: u64, key: i64, version: u64, out: &mut [u8]) {
    let mut x = seed ^ key as u64 ^ version.rotate_left(17);
    for chunk in out.chunks_mut(8) {
        x = splitmix64(x);
        let bytes = x.to_le_bytes();
        let n = chunk.len();
        chunk.copy_from_slice(&bytes[..n]);
    }
}

#[inline]
pub fn hash_bytes(bytes: &[u8]) -> u64 {
    // Simple fast non-cryptographic checksum. Replace with xxhash-rust if desired.
    let mut h = 0xcbf29ce484222325u64;
    for &b in bytes {
        h ^= b as u64;
        h = h.wrapping_mul(0x100000001b3);
    }
    h
}

#[inline]
pub fn hash_i64(x: i64) -> u64 {
    splitmix64(x as u64)
}

#[inline]
pub fn mix(a: u64, b: u64) -> u64 {
    splitmix64(a ^ b.rotate_left(31))
}

#[inline]
fn splitmix64(mut x: u64) -> u64 {
    x = x.wrapping_add(0x9e3779b97f4a7c15);
    let mut z = x;
    z = (z ^ (z >> 30)).wrapping_mul(0xbf58476d1ce4e5b9);
    z = (z ^ (z >> 27)).wrapping_mul(0x94d049bb133111eb);
```

# Threaded runner

This is the core benchmark loop. It uses:

```text
one connection per worker;
barrier start;
per-worker histograms;
no global latency lock;
one atomic operation counter;
optional duration stop flag;
checkpoint worker outside the hot path;
verification after run.
```

```rust
// src/runner/threaded.rs

use crate::config::{BenchConfig, KeyDistribution};
use crate::engines::traits::{BenchEngine, KvOps};
use crate::metrics::{LatencySummary, WorkerMetrics};
use crate::random::WorkerRng;
use anyhow::{Context, Result};
use crossbeam_utils::CachePadded;
use hdrhistogram::Histogram;
use std::path::Path;
use std::sync::{
    atomic::{AtomicBool, AtomicU64, Ordering},
    Arc, Barrier,
};
use std::thread;
use std::time::{Duration, Instant};

pub trait Workload<E: BenchEngine>: Sync {
    fn name(&self) -> &'static str;

    fn setup(&self, conn: &mut E::Conn<'_>, cfg: &BenchConfig) -> Result<()>;

    fn warmup(
        &self,
        conn: &mut E::Conn<'_>,
        cfg: &BenchConfig,
        worker_id: usize,
    ) -> Result<()> {
        let mut rng = WorkerRng::new(cfg.seed ^ 0xfeed_beef, worker_id);
        let mut scratch = vec![0u8; cfg.value_size];
        for i in 0..cfg.warmup_operations {
            self.execute_one(conn, cfg, worker_id, i, &mut rng, &mut scratch)?;
        }
        Ok(())
    }

    fn execute_one(
        &self,
        conn: &mut E::Conn<'_>,
        cfg: &BenchConfig,
        worker_id: usize,
        op_index: u64,
        rng: &mut WorkerRng,
        scratch: &mut [u8],
    ) -> Result<u64>;

    fn verify(&self, conn: &mut E::Conn<'_>, cfg: &BenchConfig) -> Result<VerifyResult>;
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct VerifyResult {
    pub verified: bool,
    pub row_count: Option<u64>,
    pub checksum: Option<u64>,
    pub details: Vec<String>,
}

#[derive(Debug, Clone, serde::Serialize, serde::Deserialize)]
pub struct ThreadedRunSummary {
    pub elapsed_ns: u64,
    pub ops_attempted: u64,
    pub ops_completed: u64,
    pub ops_failed: u64,
    pub throughput_ops_sec: f64,
    pub checksum: u64,
    pub latency: LatencySummary,
    pub verify: VerifyResult,
}

pub fn run_threaded<E, W>(db_path: &Path, cfg: &BenchConfig, workload: &W) -> Result<ThreadedRunSummary>
where
    E: BenchEngine,
    W: Workload<E>,
{
    E::create_database(db_path, cfg)?;

    {
        let mut admin = E::open_worker(usize::MAX, db_path, cfg)?;
        workload.setup(&mut admin, cfg)?;
    }

    let next_op = Arc::new(CachePadded::new(AtomicU64::new(0)));
    let stop = Arc::new(AtomicBool::new(false));
    let start_barrier = Arc::new(Barrier::new(cfg.workers + 1));

    let operation_limit = cfg.operations.unwrap_or(u64::MAX);
    let duration = cfg.duration_secs.map(Duration::from_secs);

    let mut reports = Vec::with_capacity(cfg.workers);
    let global_start = Instant::now();

    thread::scope(|scope| {
        let mut handles = Vec::with_capacity(cfg.workers);

        for worker_id in 0..cfg.workers {
            let next_op = Arc::clone(&next_op);
            let stop = Arc::clone(&stop);
            let start_barrier = Arc::clone(&start_barrier);
            let db_path = db_path.to_path_buf();

            handles.push(scope.spawn(move || -> Result<WorkerMetrics> {
                if cfg.pin_threads {
                    crate::affinity::pin_current_thread(worker_id).ok();
                }

                let mut conn = E::open_worker(worker_id, &db_path, cfg)
                    .with_context(|| format!("open worker connection {worker_id}"))?;

                conn.prepare_kv_statements()?;
                workload.warmup(&mut conn, cfg, worker_id)?;

                let mut metrics = WorkerMetrics::new();
                let mut rng = WorkerRng::new(cfg.seed, worker_id);
                let mut scratch = vec![0u8; cfg.value_size];

                start_barrier.wait();

                loop {
                    if stop.load(Ordering::Relaxed) {
                        break;
                    }

                    let op_index = next_op.fetch_add(1, Ordering::Relaxed);
                    if op_index >= operation_limit {
                        break;
                    }

                    let t0 = Instant::now();
                    match workload.execute_one(
                        &mut conn,
                        cfg,
                        worker_id,
                        op_index,
                        &mut rng,
                        &mut scratch,
                    ) {
                        Ok(checksum_delta) => metrics.record_success(t0.elapsed(), checksum_delta),
                        Err(_) => metrics.record_failure(t0.elapsed()),
                    }
                }

                Ok(metrics)
            }));
        }

        start_barrier.wait();

        if let Some(duration) = duration {
            thread::sleep(duration);
            stop.store(true, Ordering::Relaxed);
        }

        for handle in handles {
            reports.push(handle.join().expect("worker thread panicked")?);
        }

        Ok::<_, anyhow::Error>(())
    })?;

    let elapsed = global_start.elapsed();

    let mut merged_hist = Histogram::<u64>::new_with_bounds(1, 3_600_000_000_000, 3)?;
    let mut ops_attempted = 0;
    let mut ops_completed = 0;
    let mut ops_failed = 0;
    let mut checksum = 0;

    for r in reports {
        ops_attempted += r.ops_attempted;
        ops_completed += r.ops_completed;
        ops_failed += r.ops_failed;
        checksum ^= r.checksum;
        merged_hist.add(&r.latency)?;
    }

    let verify = if cfg.verify_after_run {
        let mut admin = E::open_worker(usize::MAX - 1, db_path, cfg)?;
        workload.verify(&mut admin, cfg)?
    } else {
        VerifyResult {
            verified: false,
            row_count: None,
            checksum: None,
            details: vec!["verification disabled".to_string()],
        }
    };

    Ok(ThreadedRunSummary {
        elapsed_ns: elapsed.as_nanos() as u64,
        ops_attempted,
        ops_completed,
        ops_failed,
        throughput_ops_sec: ops_completed as f64 / elapsed.as_secs_f64(),
        checksum,
        latency: LatencySummary::from_histogram(&merged_hist),
        verify,
    })
}
```

```rust
            KeyDistribution::DisjointPerWorker => {
                rng.disjoint_key(worker_id, cfg.workers, cfg.initial_rows)
            }
            KeyDistribution::Zipf { .. } => rng.uniform_key(cfg.initial_rows.min(10_000)),
        }
    }

    fn name(&self) -> &'static str {
        "mixed_oltp"

        crate::workloads::kv::load_initial_kv(conn, cfg)
    }

        cfg: &BenchConfig,
        worker_id: usize,
        op_index: u64,
        rng: &mut WorkerRng,
        scratch: &mut [u8],
    ) -> Result<u64> {

                + op_index as i64;
            make_payload(cfg.seed, key, 0, scratch);
            conn.insert_kv(key, scratch, key % 1024)?;
            Ok(hash_i64(key))

            let (_rows, checksum) = conn.range_scan_kv(key, cfg.range_len)?;
```


The point is to measure SQLite, not a high-level wrapper’s allocations.

## SQLite FFI helpers

```rust
// src/engines/sqlite_ffi.rs

#![cfg(feature = "sqlite")]

use anyhow::{anyhow, bail, Result};
use libsqlite3_sys as ffi;
use std::ffi::{CStr, CString};
use std::os::raw::{c_char, c_int};
use std::path::Path;
use std::ptr;
use std::time::Instant;

pub struct RawSqlite {
    db: *mut ffi::sqlite3,
}

pub struct RawStmt {
    stmt: *mut ffi::sqlite3_stmt,
}

impl RawSqlite {
    pub fn open(path: &Path, nomutex: bool) -> Result<Self> {
        let path = CString::new(path.to_string_lossy().as_bytes())?;
        let mut db: *mut ffi::sqlite3 = ptr::null_mut();

        let mut flags = ffi::SQLITE_OPEN_READWRITE | ffi::SQLITE_OPEN_CREATE;
        if nomutex {
            flags |= ffi::SQLITE_OPEN_NOMUTEX;
        } else {
            flags |= ffi::SQLITE_OPEN_FULLMUTEX;
        }

        let rc = unsafe {
            ffi::sqlite3_open_v2(path.as_ptr(), &mut db, flags, ptr::null())
        };

        if rc != ffi::SQLITE_OK {
            let msg = if db.is_null() {
                "sqlite3_open_v2 failed".to_string()
            } else {
                unsafe { error_message(db) }
            };
            if !db.is_null() {
                unsafe { ffi::sqlite3_close_v2(db) };
            }
            bail!(msg);
        }

        unsafe {
            ffi::sqlite3_extended_result_codes(db, 1);
        }

        Ok(Self { db })
    }

    pub fn exec(&mut self, sql: &str) -> Result<()> {
        let sql = CString::new(sql)?;
        let mut errmsg: *mut c_char = ptr::null_mut();

        let rc = unsafe {
            ffi::sqlite3_exec(
                self.db,
                sql.as_ptr(),
                None,
                ptr::null_mut(),
                &mut errmsg,
            )
        };

        if rc != ffi::SQLITE_OK {
            let msg = unsafe {
                if errmsg.is_null() {
                    error_message(self.db)
                } else {
                    let s = CStr::from_ptr(errmsg).to_string_lossy().into_owned();
                    ffi::sqlite3_free(errmsg as *mut _);
                    s
                }
            };
            bail!(msg);
        }

        Ok(())
    }

    pub fn prepare(&mut self, sql: &str) -> Result<RawStmt> {
        let sql = CString::new(sql)?;
        let mut stmt: *mut ffi::sqlite3_stmt = ptr::null_mut();

        let rc = unsafe {
            ffi::sqlite3_prepare_v3(
                self.db,
                sql.as_ptr(),
                -1,
                ffi::SQLITE_PREPARE_PERSISTENT as u32,
                &mut stmt,
                ptr::null_mut(),
            )
        };

        if rc != ffi::SQLITE_OK {
            bail!(unsafe { error_message(self.db) });
        }

        Ok(RawStmt { stmt })
    }

    pub fn busy_timeout(&mut self, ms: u32) -> Result<()> {
        let rc = unsafe { ffi::sqlite3_busy_timeout(self.db, ms as c_int) };
        if rc != ffi::SQLITE_OK {
            bail!(unsafe { error_message(self.db) });
        }
        Ok(())
    }

    pub fn checkpoint(&mut self, mode: crate::config::CheckpointMode) -> Result<(i32, i32)> {
        let mode = match mode {
            crate::config::CheckpointMode::Passive => ffi::SQLITE_CHECKPOINT_PASSIVE,
            crate::config::CheckpointMode::Full => ffi::SQLITE_CHECKPOINT_FULL,
            crate::config::CheckpointMode::Restart => ffi::SQLITE_CHECKPOINT_RESTART,
            crate::config::CheckpointMode::Truncate => ffi::SQLITE_CHECKPOINT_TRUNCATE,
        };

        let mut log_frames = 0;
        let mut ckpt_frames = 0;

        let rc = unsafe {
            ffi::sqlite3_wal_checkpoint_v2(
                self.db,
                ptr::null(),
                mode,
                &mut log_frames,
                &mut ckpt_frames,
            )
        };

        if rc != ffi::SQLITE_OK && rc != ffi::SQLITE_BUSY {
            bail!(unsafe { error_message(self.db) });
        }

        Ok((log_frames, ckpt_frames))
    }

    pub fn db_status64(&mut self, op: c_int, reset: bool) -> Result<(i64, i64)> {
        let mut cur: ffi::sqlite3_int64 = 0;
        let mut hi: ffi::sqlite3_int64 = 0;

        let rc = unsafe {
            ffi::sqlite3_db_status64(
                self.db,
                op,
                &mut cur,
                &mut hi,
                if reset { 1 } else { 0 },
            )
        };

        if rc != ffi::SQLITE_OK {
            bail!(unsafe { error_message(self.db) });
        }

        Ok((cur as i64, hi as i64))
    }
}

impl RawStmt {
    #[inline]
    pub fn bind_i64(&mut self, idx: c_int, value: i64) -> Result<()> {
        let rc = unsafe { ffi::sqlite3_bind_int64(self.stmt, idx, value) };
        if rc != ffi::SQLITE_OK {
            bail!("sqlite bind_i64 failed: rc={rc}");
        }
        Ok(())
    }

    #[inline]
    pub fn bind_blob_transient(&mut self, idx: c_int, bytes: &[u8]) -> Result<()> {
        let rc = unsafe {
            ffi::sqlite3_bind_blob64(
                self.stmt,
                idx,
                bytes.as_ptr() as *const _,
                bytes.len() as u64,
                sqlite_transient(),
            )
        };

        if rc != ffi::SQLITE_OK {
            bail!("sqlite bind_blob failed: rc={rc}");
        }

        Ok(())
    }

    #[inline]
    pub fn step_done(&mut self) -> Result<()> {
        let rc = unsafe { ffi::sqlite3_step(self.stmt) };
        match rc {
            ffi::SQLITE_DONE => Ok(()),
            ffi::SQLITE_BUSY => bail!("SQLITE_BUSY"),
            ffi::SQLITE_LOCKED => bail!("SQLITE_LOCKED"),
            _ => bail!("sqlite step_done failed: rc={rc}"),
        }
    }

    #[inline]
    pub fn step_row_or_done(&mut self) -> Result<c_int> {
        let rc = unsafe { ffi::sqlite3_step(self.stmt) };
        match rc {
            ffi::SQLITE_ROW | ffi::SQLITE_DONE => Ok(rc),
            ffi::SQLITE_BUSY => bail!("SQLITE_BUSY"),
            ffi::SQLITE_LOCKED => bail!("SQLITE_LOCKED"),
            _ => bail!("sqlite step failed: rc={rc}"),
        }
    }

    #[inline]
    pub fn column_i64(&self, idx: c_int) -> i64 {
        unsafe { ffi::sqlite3_column_int64(self.stmt, idx) }
    }

    #[inline]
    pub fn column_blob_hash(&self, idx: c_int) -> u64 {
        let ptr = unsafe { ffi::sqlite3_column_blob(self.stmt, idx) };
        let len = unsafe { ffi::sqlite3_column_bytes(self.stmt, idx) };

        if ptr.is_null() || len <= 0 {
            return 0;
        }

        let bytes = unsafe { std::slice::from_raw_parts(ptr as *const u8, len as usize) };
        crate::checksum::hash_bytes(bytes)
    }

    #[inline]
    pub fn reset_clear(&mut self) -> Result<()> {
        let rc1 = unsafe { ffi::sqlite3_reset(self.stmt) };
        let rc2 = unsafe { ffi::sqlite3_clear_bindings(self.stmt) };

        if rc1 != ffi::SQLITE_OK {
            bail!("sqlite reset failed: rc={rc1}");
        }
        if rc2 != ffi::SQLITE_OK {
            bail!("sqlite clear_bindings failed: rc={rc2}");
        }

        Ok(())
    }

    pub fn finalize(&mut self) {
        if !self.stmt.is_null() {
            unsafe {
                ffi::sqlite3_finalize(self.stmt);
            }
            self.stmt = ptr::null_mut();
        }
    }
}

impl Drop for RawStmt {
    fn drop(&mut self) {
        self.finalize();
    }
}

impl Drop for RawSqlite {
    fn drop(&mut self) {
        if !self.db.is_null() {
            unsafe {
                ffi::sqlite3_close_v2(self.db);
            }
            self.db = ptr::null_mut();
        }
    }
}

unsafe fn error_message(db: *mut ffi::sqlite3) -> String {
    CStr::from_ptr(ffi::sqlite3_errmsg(db))
        .to_string_lossy()
        .into_owned()
}

#[inline]
unsafe fn sqlite_transient() -> ffi::sqlite3_destructor_type {
    // SQLITE_TRANSIENT is ((sqlite3_destructor_type)-1).
    std::mem::transmute::<isize, ffi::sqlite3_destructor_type>(-1)
}
```

```rust
            insert_kv: None,
            update_kv: None,
            delete_kv: None,
            point_read: None,

        cfg: &BenchConfig,

        let mut db = RawSqlite::open(path, cfg.sqlite.open_nomutex)?;
        db.busy_timeout(cfg.busy_timeout_ms)?;

        let t0 = Instant::now();
        let (log, ckpt) = db.checkpoint(mode)?;
        let elapsed = t0.elapsed().as_nanos() as u64;

        Ok(CheckpointStats {
            calls: 1,
            completed: if log >= 0 && ckpt >= 0 && log == ckpt { 1 } else { 0 },
            blocked_or_busy: if log != ckpt { 1 } else { 0 },
            total_frames: log.max(0) as u64,
            checkpointed_frames: ckpt.max(0) as u64,
            total_ns: elapsed,
            max_ns: elapsed,
        })
    }

    fn collect_engine_stats(path: &Path, cfg: &BenchConfig) -> Result<EngineStats> {
        let mut db = RawSqlite::open(path, cfg.sqlite.open_nomutex)?;

        let (cache_used, _) = db.db_status64(ffi::SQLITE_DBSTATUS_CACHE_USED, false)?;
        let (cache_hit, _) = db.db_status64(ffi::SQLITE_DBSTATUS_CACHE_HIT, false)?;
        let (cache_miss, _) = db.db_status64(ffi::SQLITE_DBSTATUS_CACHE_MISS, false)?;
        let (cache_write, _) = db.db_status64(ffi::SQLITE_DBSTATUS_CACHE_WRITE, false)?;

        Ok(EngineStats {
            wal_bytes_written: Some(cache_write.max(0) as u64 * cfg.sqlite.page_size as u64),
            data_bytes_written: None,
            cache_hits: Some(cache_hit.max(0) as u64),
            cache_misses: Some(cache_miss.max(0) as u64),
            dirty_pages: None,
            checkpoint_count: None,
            custom: serde_json::json!({

                "sqlite_cache_write_pages": cache_write,
            }),
        })
    }

    fn integrity_check(path: &Path, cfg: &BenchConfig) -> Result<String> {
        let mut db = RawSqlite::open(path, cfg.sqlite.open_nomutex)?;
        apply_sqlite_pragmas(&mut db, cfg)?;

        let mut stmt = db.prepare("PRAGMA integrity_check;")?;
        let rc = stmt.step_row_or_done()?;

        if rc == ffi::SQLITE_ROW {
            // Simplified. Add column_text helper for real code.
            stmt.reset_clear()?;
            Ok("ok".to_string())
        } else {
            Ok("no rows from integrity_check".to_string())
        }
    }
}

fn apply_sqlite_pragmas(db: &mut RawSqlite, cfg: &BenchConfig) -> Result<()> {
    db.exec("PRAGMA journal_mode = WAL;")?;

    match cfg.durability {
        DurabilityMode::StrictFull => db.exec("PRAGMA synchronous = FULL;")?,
        DurabilityMode::Normal => db.exec("PRAGMA synchronous = NORMAL;")?,
        DurabilityMode::Unsafe => db.exec("PRAGMA synchronous = OFF;")?,
    }

    db.exec("PRAGMA wal_autocheckpoint = 0;")?;
    db.exec(&format!("PRAGMA busy_timeout = {};", cfg.busy_timeout_ms))?;

    if cfg.sqlite.temp_store_memory {
        db.exec("PRAGMA temp_store = MEMORY;")?;
    }

    if cfg.memory.mmap {
        db.exec("PRAGMA mmap_size = 268435456;")?;
    } else {
        db.exec("PRAGMA mmap_size = 0;")?;
    }

    let per_conn_cache_kib = (cfg.memory.db_cache_bytes / cfg.workers.max(1) as u64) / 1024;
    db.exec(&format!("PRAGMA cache_size = -{};", per_conn_cache_kib.max(64)))?;

    if cfg.sqlite.cache_spill {
        db.exec("PRAGMA cache_spill = ON;")?;
    } else {
        db.exec("PRAGMA cache_spill = OFF;")?;
    }

    db.exec("PRAGMA foreign_keys = ON;")?;

    Ok(())
}

impl<'a> KvOps for SqliteConn<'a> {
    fn setup_schema(&mut self) -> Result<()> {
        self.db.exec(
            r#"
            CREATE TABLE IF NOT EXISTS kv (
                k INTEGER PRIMARY KEY,
                v BLOB NOT NULL,
                n INTEGER NOT NULL,
                pad TEXT,
                version INTEGER NOT NULL DEFAULT 0
            );
            CREATE INDEX IF NOT EXISTS idx_kv_n ON kv(n);
            "#,
        )?;
        Ok(())
    }

    fn prepare_kv_statements(&mut self) -> Result<()> {
        self.insert_kv = Some(self.db.prepare(
            "INSERT INTO kv(k, v, n, version) VALUES(?1, ?2, ?3, 0);"
        )?);

        self.update_kv = Some(self.db.prepare(
            "UPDATE kv SET v = ?2, version = version + 1 WHERE k = ?1;"
        )?);

        self.delete_kv = Some(self.db.prepare(
            "DELETE FROM kv WHERE k = ?1;"
        )?);

        self.point_read = Some(self.db.prepare(
            "SELECT v, version FROM kv WHERE k = ?1;"
        )?);

        self.range_scan = Some(self.db.prepare(
            "SELECT k, v, version FROM kv WHERE k >= ?1 ORDER BY k LIMIT ?2;"
        )?);

        self.indexed_lookup = Some(self.db.prepare(
            "SELECT k, v, version FROM kv WHERE n = ?1 ORDER BY k LIMIT ?2;"
        )?);

        Ok(())
    }

    fn begin(&mut self) -> Result<()> {
        self.db.exec("BEGIN IMMEDIATE;")
    }

    fn commit(&mut self) -> Result<()> {
        self.db.exec("COMMIT;")
    }

    fn rollback(&mut self) -> Result<()> {
        self.db.exec("ROLLBACK;")
    }

    fn insert_kv(&mut self, key: i64, value: &[u8], n: i64) -> Result<()> {
        let stmt = self.insert_kv.as_mut().context("insert statement not prepared")?;
        stmt.bind_i64(1, key)?;
        stmt.bind_blob_transient(2, value)?;
        stmt.bind_i64(3, n)?;
        let result = stmt.step_done();
        stmt.reset_clear()?;
        result
    }

    fn update_kv(&mut self, key: i64, value: &[u8]) -> Result<u64> {
        let stmt = self.update_kv.as_mut().context("update statement not prepared")?;
        stmt.bind_i64(1, key)?;
        stmt.bind_blob_transient(2, value)?;
        let result = stmt.step_done();
        stmt.reset_clear()?;
        result?;
        Ok(1)
    }

    fn delete_kv(&mut self, key: i64) -> Result<u64> {
        let stmt = self.delete_kv.as_mut().context("delete statement not prepared")?;
        stmt.bind_i64(1, key)?;
        let result = stmt.step_done();
        stmt.reset_clear()?;
        result?;
        Ok(1)
    }

    fn point_read_kv(&mut self, key: i64) -> Result<Option<u64>> {
        let stmt = self.point_read.as_mut().context("point read not prepared")?;
        stmt.bind_i64(1, key)?;

        let rc = stmt.step_row_or_done()?;
        let out = if rc == ffi::SQLITE_ROW {
            let value_hash = stmt.column_blob_hash(0);
            let version = stmt.column_i64(1);
            Some(mix(value_hash, version as u64))
        } else {
            None
        };

        stmt.reset_clear()?;
        Ok(out)
    }

    fn range_scan_kv(&mut self, start_key: i64, limit: u64) -> Result<(u64, u64)> {
        let stmt = self.range_scan.as_mut().context("range scan not prepared")?;
        stmt.bind_i64(1, start_key)?;
        stmt.bind_i64(2, limit as i64)?;

        let mut rows = 0u64;
        let mut checksum = 0u64;

        loop {
            let rc = stmt.step_row_or_done()?;
            if rc == ffi::SQLITE_DONE {
                break;
            }

            let k = stmt.column_i64(0);
            let v = stmt.column_blob_hash(1);
            let version = stmt.column_i64(2);

            rows += 1;
            checksum ^= mix(hash_i64(k), mix(v, version as u64));
        }

        stmt.reset_clear()?;
        Ok((rows, checksum))
    }

    fn indexed_lookup_n(&mut self, n: i64, limit: u64) -> Result<(u64, u64)> {
        let stmt = self.indexed_lookup.as_mut().context("indexed lookup not prepared")?;
        stmt.bind_i64(1, n)?;
        stmt.bind_i64(2, limit as i64)?;

        let mut rows = 0u64;
        let mut checksum = 0u64;

        loop {
            let rc = stmt.step_row_or_done()?;
            if rc == ffi::SQLITE_DONE {
                break;
            }

            let k = stmt.column_i64(0);
            let v = stmt.column_blob_hash(1);
            let version = stmt.column_i64(2);

            rows += 1;
            checksum ^= mix(hash_i64(k), mix(v, version as u64));
        }

        stmt.reset_clear()?;
        Ok((rows, checksum))
    }

    fn row_count(&mut self, table: &str) -> Result<u64> {
        let sql = format!("SELECT COUNT(*) FROM {table};");
        let mut stmt = self.db.prepare(&sql)?;
        let rc = stmt.step_row_or_done()?;
        let count = if rc == ffi::SQLITE_ROW {
            stmt.column_i64(0) as u64
        } else {
            0
        };
        stmt.reset_clear()?;
        Ok(count)
    }

    fn table_checksum(&mut self, table: &str) -> Result<u64> {
        let sql = format!("SELECT k, v, version FROM {table} ORDER BY k;");
        let mut stmt = self.db.prepare(&sql)?;

        let mut checksum = 0u64;

        loop {
            let rc = stmt.step_row_or_done()?;
            if rc == ffi::SQLITE_DONE {
                break;
            }

            let k = stmt.column_i64(0);
            let v = stmt.column_blob_hash(1);
            let version = stmt.column_i64(2);
            checksum ^= mix(hash_i64(k), mix(v, version as u64));
        }

        stmt.reset_clear()?;
        Ok(checksum)
    }
}
```

# Checkpoint worker

```rust
// src/runner/checkpoint.rs

use crate::config::{BenchConfig, CheckpointMode, CheckpointPolicy};
use crate::engines::traits::BenchEngine;
use crate::metrics::CheckpointStats;
use anyhow::Result;
use parking_lot::Mutex;
use std::path::PathBuf;
use std::sync::{
    atomic::{AtomicBool, Ordering},
    Arc,
};
use std::thread;
use std::time::{Duration, Instant};

pub struct CheckpointWorker {
    stop: Arc<AtomicBool>,
    stats: Arc<Mutex<CheckpointStats>>,
    handle: Option<thread::JoinHandle<()>>,
}

impl CheckpointWorker {
    pub fn start<E: BenchEngine>(
        db_path: PathBuf,
        cfg: BenchConfig,
    ) -> Result<Option<Self>> {
        let policy = cfg.checkpoint.clone();

        let (every_ms, mode) = match policy {
            CheckpointPolicy::NoneDuringRun => return Ok(None),
            CheckpointPolicy::Background { every_ms, .. } => {
                (every_ms, CheckpointMode::Passive)
            }
            CheckpointPolicy::Pressure { every_ms, mode } => {
                (every_ms, mode)
            }
        };

        let stop = Arc::new(AtomicBool::new(false));
        let stats = Arc::new(Mutex::new(CheckpointStats::default()));

        let thread_stop = Arc::clone(&stop);
        let thread_stats = Arc::clone(&stats);

        let handle = thread::spawn(move || {
            while !thread_stop.load(Ordering::Relaxed) {
                thread::sleep(Duration::from_millis(every_ms));

                let t0 = Instant::now();
                match E::checkpoint(&db_path, &cfg, mode) {
                    Ok(s) => {
                        let mut guard = thread_stats.lock();
                        guard.calls += s.calls;
                        guard.completed += s.completed;
                        guard.blocked_or_busy += s.blocked_or_busy;
                        guard.total_frames += s.total_frames;
                        guard.checkpointed_frames += s.checkpointed_frames;
                        guard.total_ns += s.total_ns;
                        guard.max_ns = guard.max_ns.max(s.max_ns);
                    }
                    Err(_) => {
                        let mut guard = thread_stats.lock();
                        guard.calls += 1;
                        guard.blocked_or_busy += 1;
                        guard.max_ns = guard.max_ns.max(t0.elapsed().as_nanos() as u64);
                    }
                }
            }
        });

        Ok(Some(Self {
            stop,
            stats,
            handle: Some(handle),
        }))
    }

    pub fn stop(mut self) -> CheckpointStats {
        self.stop.store(true, Ordering::Relaxed);
        if let Some(handle) = self.handle.take() {
            let _ = handle.join();
        }
        self.stats.lock().clone()
    }
}
```

```rust
// src/runner/process.rs

use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};
use std::time::{Duration, Instant};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ChildRunSpec {
    pub case_json: PathBuf,
    pub output_json: PathBuf,
    pub timeout_secs: u64,
}

pub fn run_child(run_one_bin: &Path, spec: &ChildRunSpec) -> Result<()> {
    let mut child = Command::new(run_one_bin)
        .arg("--case-json")
        .arg(&spec.case_json)
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .context("spawn run-one")?;

    let start = Instant::now();

    loop {
        if let Some(status) = child.try_wait()? {
            let output = child.wait_with_output()?;
            if !status.success() {
                anyhow::bail!(
                    "child failed: status={status:?}\nstdout={}\nstderr={}",
                    String::from_utf8_lossy(&output.stdout),
                    String::from_utf8_lossy(&output.stderr)

            }
            return Ok(());

        if start.elapsed() > Duration::from_secs(spec.timeout_secs) {
            let _ = child.kill();
            anyhow::bail!("child timeout after {}s", spec.timeout_secs);
        }

        std::thread::sleep(Duration::from_millis(50));
```

```rust
// src/procstat.rs

use anyhow::Result;
use std::fs;
use std::path::PathBuf;

#[derive(Debug, Clone, Copy, Default)]
pub struct ProcMemory {
    pub rss_bytes: u64,
    pub vms_bytes: u64,
    pub peak_rss_bytes: u64,
}

pub fn read_proc_status(pid: u32) -> Result<ProcMemory> {
    let path = PathBuf::from(format!("/proc/{pid}/status"));
    let text = fs::read_to_string(path)?;

    let mut out = ProcMemory::default();

    for line in text.lines() {
        if let Some(v) = line.strip_prefix("VmRSS:") {
            out.rss_bytes = parse_kib_line(v) * 1024;
        } else if let Some(v) = line.strip_prefix("VmSize:") {
            out.vms_bytes = parse_kib_line(v) * 1024;
        } else if let Some(v) = line.strip_prefix("VmHWM:") {
            out.peak_rss_bytes = parse_kib_line(v) * 1024;
        }
    }

    Ok(out)
}

fn parse_kib_line(s: &str) -> u64 {
    s.split_whitespace()
        .next()
        .and_then(|x| x.parse::<u64>().ok())
        .unwrap_or(0)
}
```

## Ack protocol

The child must tell the parent which commits were acknowledged.

```text
child:
  begin tx
  write row key = seq
  commit returns
  send ACK(seq, key, value_hash) over pipe
  continue

parent:
  receive ACK
  append to ack.log
  fsync ack.log
  randomly SIGKILL child
  reopen DB
  verify every ACK exists
```

Do not let the child keep the only list of acknowledged commits. If the child dies, you lose the truth.

```rust
// src/runner/crash.rs

use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};
use std::fs::{File, OpenOptions};
use std::io::{BufRead, BufReader, Write};
use std::os::unix::process::ExitStatusExt;
use std::path::{Path, PathBuf};
use std::process::{Command, Stdio};
use std::time::{Duration, Instant};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Ack {
    pub seq: u64,
    pub key: i64,
    pub value_hash: u64,
}

pub fn append_ack_log(path: &Path, ack: &Ack) -> Result<()> {
    let mut f = OpenOptions::new()
        .create(true)
        .append(true)
        .open(path)?;

    serde_json::to_writer(&mut f, ack)?;
    f.write_all(b"\n")?;
    f.sync_data()?;
    Ok(())
}

pub fn read_ack_log(path: &Path) -> Result<Vec<Ack>> {
    let f = File::open(path)?;
    let reader = BufReader::new(f);
    let mut out = Vec::new();

    for line in reader.lines() {
        let line = line?;
        if line.trim().is_empty() {
            continue;
        }
        out.push(serde_json::from_str(&line)?);
    }

    Ok(out)
}

pub fn crash_child_after_acks(
    run_one_bin: &Path,
    case_json: &Path,
    ack_log: &Path,
    min_acks: usize,
    max_runtime: Duration,
) -> Result<()> {
    let mut child = Command::new(run_one_bin)
        .arg("--case-json")
        .arg(case_json)
        .arg("--crash-ack-mode")
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .context("spawn crash child")?;

    let stdout = child.stdout.take().context("child stdout")?;
    let mut reader = BufReader::new(stdout);

    let start = Instant::now();
    let mut ack_count = 0usize;
    let mut line = String::new();

    while start.elapsed() < max_runtime {
        line.clear();
        if reader.read_line(&mut line)? == 0 {
            break;
        }

        if let Some(json) = line.strip_prefix("ACK ") {
            let ack: Ack = serde_json::from_str(json.trim())?;
            append_ack_log(ack_log, &ack)?;
            ack_count += 1;

            if ack_count >= min_acks {
                let _ = child.kill();
                let status = child.wait()?;
                if status.signal().is_some() {
                    return Ok(());
                }
                anyhow::bail!("child exited without signal: {status:?}");
            }
        }
    }

    let _ = child.kill();
    anyhow::bail!("did not receive enough ACKs before timeout");
}
```

# Release gates

Phase 9 should define gates in order. Do not let speed claims bypass correctness.

## Gate 0: benchmark harness sanity

```text
NullEngine overhead < 2% of measured DB latency for target workloads,
or benchmark reports overhead separately.

Identical seeds produce identical operation streams.

SQLite version and compile options recorded.

All result JSON validates schema.

Each benchmark creates fresh DB directory unless explicitly testing reopen.

Every workload has post-run row count/checksum verification.
```

## Gate 1: SQL correctness

```text
100% pass on supported sqllogictest files.

100% pass on deterministic differential SQL subset.

No silent unsupported behavior.

Every supported error class matches expected behavior.

All benchmark workloads verify final checksums.
```

## Gate 2: durability/recovery

```text
Strict mode:
  zero missing acknowledged commits after process kill;
  zero corruption after reopen;
  bounded recovery time;
  integrity check passes.

Normal mode:
  process-kill recovery preserves acknowledged commits;
  report clearly states power-loss durability caveat.

Unsafe mode:
  never used in replacement claims.
```

## Gate 3: single-thread parity

For replacement status, RedlineDB should be close to SQLite before claiming victory:

```text
single-thread point read:
  RedlineDB throughput >= 0.90x SQLite
  RedlineDB p99 <= 1.25x SQLite

single-thread insert strict:
  RedlineDB throughput >= 0.90x SQLite
  RedlineDB p99 <= 1.25x SQLite

single-thread range scan:
  RedlineDB throughput >= 0.90x SQLite

database size:
  RedlineDB <= 1.25x SQLite for equivalent rows/indexes
```

These thresholds can be tightened later. The important point is to prevent “we beat SQLite only at 64 writers” from hiding poor basic embedded performance.

## Gate 4: concurrent-writer advantage

For disjoint writer workloads:

```text
workers = 4:
  RedlineDB throughput >= 1.5x SQLite

workers = 8:
  RedlineDB throughput >= 2.0x SQLite

workers = 16:
  RedlineDB throughput >= 3.0x SQLite

p99 latency:
  RedlineDB p99 <= SQLite p99 under same mode

failures:
  zero failed operations
```

The exact multipliers should be tuned after the first full baseline, but RedlineDB should clearly win here if its architecture avoids SQLite’s single-writer bottleneck.

## Gate 5: memory discipline

```text
Configured DB cache is honored.

Peak RSS <= configured cache + benchmark scratch + engine overhead allowance.

No unbounded WAL growth under background checkpoint with no long readers.

With long readers, WAL growth is explained and bounded by configured retention or reported as blocked.
```

## Gate 6: checkpoint behavior

```text
Background checkpoint:
  no catastrophic p99.9 spikes under normal workload.

Checkpoint pressure:
  stalls are measured and reported.

Long reader:
  checkpoint blocked/partial progress is detected.
```

## Gate 7: report honesty

Every release report must include:

```text
unsupported SQLite features;
durability profile;
SQLite settings;
RedlineDB settings;
machine metadata;
raw JSON artifacts;
number of repetitions;
median and spread;
all failed/skipped tests;
known caveats.
```

# Gate evaluator

```rust
// src/gates.rs

use anyhow::{bail, Result};
use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GateDecision {
    pub name: String,
    pub passed: bool,
    pub reason: String,
}

pub fn ratio_at_least(name: &str, redline: f64, sqlite: f64, min_ratio: f64) -> GateDecision {
    let ratio = redline / sqlite.max(1e-9);
    GateDecision {
        name: name.to_string(),
        passed: ratio >= min_ratio,
        reason: format!(
            "redline={redline:.3}, sqlite={sqlite:.3}, ratio={ratio:.3}, required={min_ratio:.3}"
        ),
    }
}

pub fn latency_at_most_ratio(
    name: &str,
    redline_ns: u64,
    sqlite_ns: u64,
    max_ratio: f64,
) -> GateDecision {
    let ratio = redline_ns as f64 / (sqlite_ns.max(1) as f64);
    GateDecision {
        name: name.to_string(),
        passed: ratio <= max_ratio,
        reason: format!(
            "redline_ns={redline_ns}, sqlite_ns={sqlite_ns}, ratio={ratio:.3}, required<={max_ratio:.3}"
        ),
    }
}

pub fn require_all(decisions: &[GateDecision]) -> Result<()> {
    let failed: Vec<_> = decisions.iter().filter(|d| !d.passed).collect();

    if !failed.is_empty() {
        for f in &failed {
            eprintln!("FAILED {}: {}", f.name, f.reason);
        }
        bail!("{} gates failed", failed.len());
    }

    Ok(())
}
```

```rust
fn run_engine<E: crate::engines::traits::BenchEngine>(cfg: &BenchConfig) -> Result<()> {

    let db_path = &cfg.db_path;

    let summary = match cfg.workload {
        WorkloadKind::SingleRowInsert => {
            run_threaded::<E, _>(db_path, cfg, &crate::workloads::insert::SingleRowInsert)?
        }
        WorkloadKind::PointReadPk => {
            run_threaded::<E, _>(db_path, cfg, &crate::workloads::point_read::PointReadPk)?
        }
        WorkloadKind::MixedOltp => {
            let w = crate::workloads::mixed_oltp::MixedOltp {
                read_pct: 80,
                update_pct: 15,
                insert_pct: 2,
                range_pct: 3,
            };
            run_threaded::<E, _>(db_path, cfg, &w)?
        }
        _ => anyhow::bail!("workload not implemented yet: {:?}", cfg.workload),
    };

    let json = serde_json::to_vec_pretty(&summary)?;
    fs::write(&cfg.output_json, json)?;

    Ok(())
}
```

# Null engine

The `NullEngine` is important. It quantifies benchmark overhead.

```rust
// src/engines/null.rs

use crate::checksum::{hash_i64, hash_bytes};
use crate::config::{BenchConfig, CheckpointMode};
use crate::engines::traits::{BenchEngine, KvOps};
use crate::metrics::{CheckpointStats, EngineStats};
use anyhow::Result;
use std::path::Path;

pub struct NullEngine;

pub struct NullConn {
    rows: u64,
}

impl BenchEngine for NullEngine {
    type Conn<'a> = NullConn;

    fn name() -> &'static str {
        "null"
    }

    fn create_database(_path: &Path, _cfg: &BenchConfig) -> Result<()> {
        Ok(())
    }

    fn open_worker<'a>(
        _worker_id: usize,
        _path: &'a Path,
        cfg: &'a BenchConfig,
    ) -> Result<Self::Conn<'a>> {
        Ok(NullConn {
            rows: cfg.initial_rows,
        })
    }

    fn checkpoint(
        _path: &Path,
        _cfg: &BenchConfig,
        _mode: CheckpointMode,
    ) -> Result<CheckpointStats> {
        Ok(CheckpointStats::default())
    }

    fn collect_engine_stats(_path: &Path, _cfg: &BenchConfig) -> Result<EngineStats> {
        Ok(EngineStats::default())
    }

    fn integrity_check(_path: &Path, _cfg: &BenchConfig) -> Result<String> {
        Ok("ok".to_string())
    }
}

impl KvOps for NullConn {
    fn setup_schema(&mut self) -> Result<()> { Ok(()) }
    fn prepare_kv_statements(&mut self) -> Result<()> { Ok(()) }
    fn begin(&mut self) -> Result<()> { Ok(()) }
    fn commit(&mut self) -> Result<()> { Ok(()) }
    fn rollback(&mut self) -> Result<()> { Ok(()) }

    fn insert_kv(&mut self, _key: i64, _value: &[u8], _n: i64) -> Result<()> {
        self.rows += 1;
        Ok(())
    }

    fn update_kv(&mut self, _key: i64, _value: &[u8]) -> Result<u64> {
        Ok(1)
    }

    fn delete_kv(&mut self, _key: i64) -> Result<u64> {
        Ok(1)
    }

    fn point_read_kv(&mut self, key: i64) -> Result<Option<u64>> {
        Ok(Some(hash_i64(key)))
    }

    fn range_scan_kv(&mut self, start_key: i64, limit: u64) -> Result<(u64, u64)> {
        let mut checksum = 0;
        for k in start_key..start_key + limit as i64 {
            checksum ^= hash_i64(k);
        }
        Ok((limit, checksum))
    }

    fn indexed_lookup_n(&mut self, n: i64, limit: u64) -> Result<(u64, u64)> {
        Ok((limit, hash_i64(n) ^ limit))
    }

    fn row_count(&mut self, _table: &str) -> Result<u64> {
        Ok(self.rows)
    }

    fn table_checksum(&mut self, _table: &str) -> Result<u64> {
        Ok(self.rows.rotate_left(17))
    }
}
```

Gate:

```text

the benchmark is too dominated by harness overhead.
```

# Performance engineering inside the harness

To keep the benchmark from becoming the bottleneck:

```text
1. One worker thread per connection.
2. No global histogram lock.
3. No per-operation logging.
4. No per-operation allocation.
5. Prepared statements created before timed section.
6. Preallocated payload scratch per worker.
7. Deterministic PRNG per worker.
8. Optional pregenerated request stream for high-fidelity runs.
9. Atomic operation counter only for fixed-operation tests.
10. Duration tests use stop flag and local op counts.
11. Checkpoint metrics gathered off the hot path.
12. Process RSS sampled by parent, not by every worker.
13. Pin threads only when the benchmark config says so.
14. Record failed ops, never silently retry inside the harness.
```

For SQLite specifically:

```text
1. Use one connection per worker.
2. Use SQLITE_OPEN_NOMUTEX only when the connection is single-thread-owned.
3. Use sqlite3_prepare_v3 + SQLITE_PREPARE_PERSISTENT.
4. Reuse statements.
5. Bind/reset/clear; do not finalize per operation.
6. Use explicit BEGIN IMMEDIATE for batched writer transactions.
7. Disable auto-checkpoint and run benchmark-controlled checkpoint worker.
```

# How to handle `SQLITE_BUSY`

For contention workloads, `SQLITE_BUSY` is not a harness bug. It is a result.

Policy:

```text
If workload is supposed to complete all operations:
  busy after timeout = failed operation.
  report failures.
  gate requires zero failures for release claims.

If workload is explicitly a contention stress test:
  busy count is a metric.
  report busy rate and latency.
```

Do not spin in Rust above SQLite. Let SQLite’s busy handler implement the wait so the latency is naturally included. The busy timeout behavior is documented by SQLite. ([SQLite][6])

---

# WAL bytes/op and data bytes/op

Use multiple sources because no single metric is perfect.

For SQLite:

```text
1. SQLITE_DBSTATUS_CACHE_WRITE * page_size:
   approximate pages written to WAL in WAL mode.

2. /proc/<pid>/io write_bytes:
   actual kernel write bytes where available.

3. file sizes:
   db, -wal, -shm at start/end/max.

4. checkpoint frames:
   sqlite3_wal_checkpoint_v2 output.
```

SQLite documents `SQLITE_DBSTATUS_CACHE_WRITE` as dirty cache entries written to disk and specifically notes that in WAL mode this means pages written to the WAL file. ([SQLite][2])

For RedlineDB:

```text
1. exact WAL bytes appended from WAL writer;
2. exact data bytes written by page writer/checkpointer;
3. fsync count;
4. checkpoint pages;
5. segment rotation count;
6. dirty-page flush count.
```

The report should label SQLite WAL bytes as approximate if using cache-write pages. For RedlineDB, make it exact.

# “Beat SQLite” engineering interpretation

RedlineDB should not try to beat SQLite everywhere immediately. Phase 9 should expose where RedlineDB’s architecture pays off.

Expected win areas:

```text
concurrent disjoint writers;
mixed readers/writers with multiple write sessions;
group commit under strict durability;
large write batches with sharded buffer pool;
checkpoint scheduling under controlled policy;
lower p99 under concurrent writers once SQLite queues behind its single writer.
```

Expected hard areas:

```text
single-thread point lookup;
single-thread tiny insert;
small hot-cache reads;
small range scans;
database file compactness;
SQLite’s mature B-tree and pager behavior.
```

This is why the release gates are staged:

```text
correctness first;
strict durability;
single-thread near parity;
clear concurrent-writer win;
memory boundedness;
checkpoint/recovery honesty.
```

# One very important RedlineDB API addition

To make Phase 9 meaningful, RedlineDB should expose a stable benchmark stats API:

```rust
pub struct DbStats {
    pub memory: MemoryStats,
    pub wal: WalStats,
    pub buffer: BufferStats,
    pub tx: TxStats,
    pub locks: LockStats,
    pub checkpoint: CheckpointStats,
    pub vacuum: VacuumStats,
}

pub struct WalStats {
    pub bytes_appended: u64,
    pub records_appended: u64,
    pub fsync_count: u64,
    pub fsync_total_ns: u64,
    pub group_commit_batches: u64,
    pub group_commit_waiters: u64,
    pub max_queue_depth: u64,
}

pub struct BufferStats {
    pub hits: u64,
    pub misses: u64,
    pub evictions: u64,
    pub dirty_pages: u64,
    pub pages_flushed: u64,
}

pub struct TxStats {
    pub commits: u64,
    pub rollbacks: u64,
    pub active_snapshots: u64,
    pub oldest_csn: u64,
}

pub struct LockStats {
    pub row_lock_wait_count: u64,
    pub row_lock_wait_ns: u64,
    pub latch_wait_count: u64,
    pub latch_wait_ns: u64,
}

pub struct CheckpointStats {
    pub completed: u64,
    pub pages_written: u64,
    pub bytes_written: u64,
    pub total_ns: u64,
    pub max_ns: u64,
    pub blocked_by_readers: u64,
}
```

Without this, if RedlineDB loses a workload, you will be guessing. With this, the report can say:

```text
RedlineDB lost update_pk_zipf at 16 workers because row_lock_wait_ns dominated.
RedlineDB lost point_read_pk because buffer miss rate was high.
RedlineDB p99 spiked because checkpoint wrote 50k pages.
RedlineDB strict insert won because group commit batch size averaged 18.
```
