# Phase 7: Public APIs, C ABI, CLI, and Optional Server

Phase 7 should be treated as the **product boundary** around the engine, not as another storage-engine phase. The goal is to expose the existing RedlineDB kernel and SQL engine through APIs that are stable, fast, low-allocation, safe for Rust users, predictable for C callers, and impossible to accidentally turn into a SQLite-style global writer bottleneck.

SQLite’s ergonomic surface is worth copying: `prepare`, `bind`, `step`, `column`, `reset`, `finalize`, error codes, and backup APIs are simple and battle-tested. SQLite’s own docs describe `prepare` as constructing a prepared statement object, `step` as repeatedly evaluating it, and `SQLITE_ROW` / `SQLITE_DONE` as the core row-production states. ([SQLite][1]) But RedlineDB should **not** copy SQLite’s concurrency limitation: SQLite WAL allows readers and a writer to coexist, but because there is one WAL file, it still permits only one writer at a time. ([SQLite][2]) RedlineDB’s API layer must preserve your kernel’s ability to run many writer transactions concurrently and only converge at WAL/group-commit boundaries.

---

# 1. Phase 7 deliverable shape

Use this crate layout:

```text
redlinedb/
  crates/
    redlinedb/              # stable public Rust API
    redlinedb_core/         # existing kernel/storage
    redlinedb_sql/          # parser/binder/planner/executor
    redlinedb_api/          # shared API types, errors, values, stats
    redlinedb_ffi/          # C ABI: cdylib/staticlib
    redlinedb_cli/          # interactive CLI and smoke benchmarks
    redlinedb_server/       # optional local/TCP server, feature gated
    redlinedb_bench_api/    # API-level benchmark harness
  include/
    redlinedb.h             # generated by cbindgen
  examples/
    rust_basic.rs
    rust_concurrent.rs
    c_basic.c
    c_concurrent.c
```

The dependency direction should be strict:

```text
redlinedb_cli
    -> redlinedb

redlinedb_ffi
    -> redlinedb

redlinedb_server
    -> redlinedb

redlinedb
    -> redlinedb_sql
    -> redlinedb_core

redlinedb_api
    -> no storage dependency
```

The CLI, C ABI, and server should never call kernel internals directly. They should all go through the same public Rust API. That keeps the product surface honest and prevents three subtly different implementations of statement execution.

# 2. Non-negotiable design goals

## 2.1 Do not serialize the engine at the API layer

The number-one way to ruin RedlineDB’s advantage is to wrap the whole database in:

```rust
Arc<Mutex<Database>>
```

Do **not** do that.

The correct model is:

```text
Database / Engine:
  Send + Sync
  shared by all connections
  owns buffer pool, WAL, catalog cache, workers, stats

Connection:
  Send
  not Sync by default
  owns session state, transaction state, statement cache, busy policy

Prepared:
  Send + Sync
  immutable compiled statement / plan metadata

Running statement / cursor:
  tied to one mutable connection
  owns bindings, execution state, current row buffer
```

That gives this threading model:

```text
Thread 1: Connection A -> transaction A -> writer A
Thread 2: Connection B -> transaction B -> writer B
Thread 3: Connection C -> long reader snapshot
Thread 4: Connection D -> point reads
Background: WAL group commit, checkpoint, vacuum
```

The API layer must not introduce a single “writer mutex.” Conflicts should occur only at real kernel conflict points: row locks, index key locks, page latches, WAL reservation, commit ordering, or durability barriers.

## 2.2 Make the Rust API faster than the C ABI

The Rust API is the primary product API. The C ABI is an adapter. Therefore:

```text
Rust API:
  typed
  lifetime-aware
  mostly zero-copy
  no per-call FFI validation
  no mandatory mutex per connection

C ABI:
  opaque handles
  nullable pointer checks
  stable numeric error codes
  catch_unwind boundary
  optional serialized mutex mode
  copies C input when needed
```

The C ABI can be very fast, but the Rust API should remain the lowest-overhead path.

## 2.3 API stability means hiding internals

Do not expose these in public API:

```rust
PageId
Lsn
Csn
HeapTuple
WalRecord
BufferFrame
LatchGuard
UndoRecord
BTreePage
```

Expose these instead:

```rust
Database
Connection
Prepared
Statement
Row
Value
ValueRef
Transaction
Backup
Stats
Error
```

Internal concepts can appear in stats and debug output, but not in types that applications depend on.

# 3. Public Rust API

## 3.1 Top-level ergonomic usage

The common Rust path should look like this:

```rust
use redlinedb::{Database, OpenOptions, Durability, params};

fn main() -> redlinedb::Result<()> {
    let db = Database::open_with_options(
        "app.rdb",
        OpenOptions::new()
            .create_if_missing(true)
            .durability(Durability::Strict)
            .cache_bytes(512 * 1024 * 1024),
    )?;

    let mut conn = db.connect()?;

    conn.execute(
        "CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY, name TEXT)",
        (),
    )?;

    let insert = db.prepare("INSERT INTO users(id, name) VALUES (?, ?)")?;

    conn.transaction(|tx| {
        for i in 0..10_000_i64 {
            tx.execute_prepared(&insert, params![i, format!("user-{i}")])?;
        }
        Ok(())
    })?;

    let select = db.prepare("SELECT id, name FROM users WHERE id >= ? ORDER BY id LIMIT 10")?;

    let mut rows = conn.query_prepared(&select, params![42_i64])?;
    while let Some(row) = rows.next()? {
        let id: i64 = row.get(0)?;
        let name: &str = row.get_ref(1)?.as_str()?;
        println!("{id}: {name}");
    }

    Ok(())
}
```

Key points:

```text
Database::prepare() returns a shareable Prepared plan.
Connection::query_prepared() creates a cursor tied to that connection.
Rows::next() returns borrowed row data valid until the next call.
No Vec<Value> allocation is required per row.
```

`Connection` should be `Send` but not `Sync`:

```rust
pub struct Connection {
    db: Database,
    session: Session,
    local_cache: StatementCache,
    interrupt: Arc<AtomicBool>,
    busy_policy: BusyPolicy,

    // Cell makes Connection !Sync while still allowing Send.
    _not_sync: PhantomData<Cell<()>>,
}

unsafe impl Send for Connection {}

impl Connection {
    pub fn execute(&mut self, sql: &str, params: impl IntoParams) -> Result<Done> {
        let prepared = self.prepare_cached(sql)?;
        self.execute_prepared(&prepared, params)
    }

    pub fn query(&mut self, sql: &str, params: impl IntoParams) -> Result<Rows<'_>> {
        let prepared = self.prepare_cached(sql)?;
        self.query_prepared(&prepared, params)
    }

    pub fn prepare_cached(&mut self, sql: &str) -> Result<Prepared> {
        let schema_version = self.db.inner.catalog_schema_version();

        if let Some(p) = self.local_cache.get(sql, schema_version) {
            return Ok(p);
        }

        let prepared = self.db.prepare(sql)?;
        self.local_cache.insert(sql, schema_version, prepared.clone());
        Ok(prepared)
    }

    pub fn execute_prepared(
        &mut self,
        prepared: &Prepared,
        params: impl IntoParams,
    ) -> Result<Done> {
        let mut rows = self.query_prepared(prepared, params)?;
        loop {
            match rows.step()? {
                Step::Row(_) => continue,
                Step::Done(done) => return Ok(done),
            }
        }
    }

    pub fn query_prepared(
        &mut self,
        prepared: &Prepared,
        params: impl IntoParams,
    ) -> Result<Rows<'_>> {
        let bindings = params.into_params(prepared.parameter_count())?;

        let cursor = self.db.inner.start_statement(
            &mut self.session,
            prepared,
            bindings,
            &self.interrupt,
            &self.busy_policy,
        )?;

        Ok(Rows {
            conn: self,
            prepared: prepared.clone(),
            cursor,
            current_row: RowBuffer::new(prepared.column_count()),
            done: false,
        })
    }

    pub fn begin(&mut self, isolation: IsolationLevel) -> Result<()> {
        self.db.inner.begin(&mut self.session, isolation)
    }

    pub fn commit(&mut self) -> Result<CommitStats> {
        self.db.inner.commit(&mut self.session)
    }

    pub fn rollback(&mut self) -> Result<()> {
        self.db.inner.rollback(&mut self.session)
    }

    pub fn transaction<T>(
        &mut self,
        f: impl FnOnce(&mut Transaction<'_>) -> Result<T>,
    ) -> Result<T> {
        self.begin(IsolationLevel::Snapshot)?;

        let mut tx = Transaction { conn: self };

        match f(&mut tx) {
            Ok(value) => {
                tx.conn.commit()?;
                Ok(value)
            }
            Err(err) => {
                let _ = tx.conn.rollback();
                Err(err)
            }
        }
    }

    pub fn interrupt_handle(&self) -> InterruptHandle {
        InterruptHandle {
            flag: Arc::clone(&self.interrupt),
        }
    }

    pub fn clear_interrupt(&self) {
        self.interrupt.store(false, Ordering::Release);
    }

    pub fn set_busy_timeout(&mut self, timeout: std::time::Duration) {
        self.busy_policy = BusyPolicy::Timeout(timeout);
    }
}
```

Rows should be streaming and non-allocating:

```rust
pub struct Rows<'conn> {
    conn: &'conn mut Connection,
    prepared: Prepared,
    cursor: CursorState,
    current_row: RowBuffer,
    done: bool,
}

pub enum Step<'row> {
    Row(Row<'row>),
    Done(Done),
}

impl<'conn> Rows<'conn> {
    pub fn step(&mut self) -> Result<Step<'_>> {
        if self.done {
            return Ok(Step::Done(Done::default()));
        }

        self.current_row.clear_reuse();

        match self.conn.db.inner.step_statement(
            &mut self.conn.session,
            &mut self.cursor,
            &mut self.current_row,
            &self.conn.interrupt,
        )? {
            EngineStep::Row => {
                let row = Row {
                    meta: &self.prepared.inner.columns,
                    buf: &self.current_row,
                };
                Ok(Step::Row(row))
            }
            EngineStep::Done(done) => {
                self.done = true;
                Ok(Step::Done(done))
            }
        }
    }

    pub fn next(&mut self) -> Result<Option<Row<'_>>> {
        match self.step()? {
            Step::Row(row) => Ok(Some(row)),
            Step::Done(_) => Ok(None),
        }
    }
}
```

## 4.1 Owned values

```rust
use bytes::Bytes;

pub enum Value {

    fn from(v: f64) -> Self {
        Self::Real(v)
    }

    fn from(v: String) -> Self {
        Self::Text(Arc::<str>::from(v))
    }
}

    fn from(v: &str) -> Self {
        Self::Text(Arc::<str>::from(v))
    }

    fn from(v: Vec<u8>) -> Self {
        Self::Blob(Bytes::from(v))
    }
```

## 4.2 Borrowed values

```rust
#[derive(Debug, Clone, Copy)]
pub enum ValueRef<'a> {
    Null,
    Integer(i64),
    Real(f64),
    Text(&'a str),
    Blob(&'a [u8]),
}

impl<'a> ValueRef<'a> {
    pub fn as_i64(self) -> Result<i64> {
        match self {
            ValueRef::Integer(v) => Ok(v),
            ValueRef::Real(v) => Ok(v as i64),
            ValueRef::Text(s) => s.parse::<i64>().map_err(|_| Error::type_mismatch("integer")),
            ValueRef::Null | ValueRef::Blob(_) => Err(Error::type_mismatch("integer")),
        }
    }

    pub fn as_str(self) -> Result<&'a str> {
        match self {
            ValueRef::Text(s) => Ok(s),
            _ => Err(Error::type_mismatch("text")),
        }
    }

    pub fn as_blob(self) -> Result<&'a [u8]> {
        match self {
            ValueRef::Blob(b) => Ok(b),
            _ => Err(Error::type_mismatch("blob")),
        }
    }
}
```

## 4.3 Row buffer

The executor must never return a row while holding a page latch. It can return:

```text
small fixed-width values by copy
small text/blob values by copy into row buffer
large text/blob values as pinned page references, but no latch held
```

That gives safe column access without blocking writers or eviction too much.

```rust
pub struct RowBuffer {
    values: SmallVec<[RowSlot; 8]>,
    pins: SmallVec<[RowPin; 2]>,
    scratch: Vec<u8>,
}

pub enum RowSlot {
    Null,
    Integer(i64),
    Real(f64),

    // Owned or copied into scratch.
    TextOwned(std::ops::Range<usize>),
    BlobOwned(std::ops::Range<usize>),

    // Borrowed from a page/record pin. No latch held.
    TextPinned {
        pin_index: usize,
        offset: usize,
        len: usize,
    },
    BlobPinned {
        pin_index: usize,
        offset: usize,
        len: usize,
    },
}

impl RowBuffer {
    pub fn new(column_count: usize) -> Self {
        Self {
            values: SmallVec::with_capacity(column_count),
            pins: SmallVec::new(),
            scratch: Vec::new(),
        }
    }

    pub fn clear_reuse(&mut self) {
        self.values.clear();
        self.pins.clear();
        self.scratch.clear();
    }

    pub fn push_i64(&mut self, v: i64) {
        self.values.push(RowSlot::Integer(v));
    }

    pub fn push_text_copy(&mut self, s: &str) {
        let start = self.scratch.len();
        self.scratch.extend_from_slice(s.as_bytes());
        let end = self.scratch.len();
        self.values.push(RowSlot::TextOwned(start..end));
    }

    pub fn get(&self, index: usize) -> Option<ValueRef<'_>> {
        let slot = self.values.get(index)?;

        match slot {
            RowSlot::Null => Some(ValueRef::Null),
            RowSlot::Integer(v) => Some(ValueRef::Integer(*v)),
            RowSlot::Real(v) => Some(ValueRef::Real(*v)),
            RowSlot::TextOwned(r) => {
                let s = std::str::from_utf8(&self.scratch[r.clone()]).ok()?;
                Some(ValueRef::Text(s))
            }
            RowSlot::BlobOwned(r) => Some(ValueRef::Blob(&self.scratch[r.clone()])),
            RowSlot::TextPinned {
                pin_index,
                offset,
                len,
            } => {
                let bytes = self.pins[*pin_index].bytes(*offset, *len);
                let s = std::str::from_utf8(bytes).ok()?;
                Some(ValueRef::Text(s))
            }
            RowSlot::BlobPinned {
                pin_index,
                offset,
                len,
            } => {
                let bytes = self.pins[*pin_index].bytes(*offset, *len);
                Some(ValueRef::Blob(bytes))
            }
        }
    }
}
```

This matters for C too: `rdb_column_text()` must return a pointer valid until the next `step`, `reset`, or `finalize`, but RedlineDB should not hold kernel latches while the C caller looks at the data.

# 5. Parameters

Use a small fixed inline buffer because most SQL statements have few parameters.

```rust
pub struct Params {
    values: SmallVec<[Value; 8]>,
}

pub trait IntoParams {
    fn into_params(self, expected: usize) -> Result<Params>;
}

impl IntoParams for () {
    fn into_params(self, expected: usize) -> Result<Params> {
        if expected != 0 {
            return Err(Error::range(format!(
                "expected {expected} parameters, got 0"
            )));
        }
        Ok(Params {
            values: SmallVec::new(),
        })
    }
}

impl<const N: usize> IntoParams for [Value; N] {
    fn into_params(self, expected: usize) -> Result<Params> {
        if expected != N {
            return Err(Error::range(format!(
                "expected {expected} parameters, got {N}"
            )));
        }
        Ok(Params {
            values: SmallVec::from_buf(self),
        })
    }
}

#[macro_export]
macro_rules! params {
    () => {
        $crate::Params::empty()
    };
    ($($value:expr),+ $(,)?) => {{
        let mut p = $crate::Params::new();
        $(
            p.push($value);
        )+
        p
    }};
}

impl Params {
    pub fn new() -> Self {
        Self {
            values: SmallVec::new(),
        }
    }

    pub fn empty() -> Self {
        Self::new()
    }

    pub fn push(&mut self, value: impl Into<Value>) {
        self.values.push(value.into());
    }

    pub fn as_slice(&self) -> &[Value] {
        &self.values
    }
}

impl IntoParams for Params {
    fn into_params(self, expected: usize) -> Result<Params> {
        if self.values.len() != expected {
            return Err(Error::range(format!(
                "expected {expected} parameters, got {}",
                self.values.len()
            )));
        }
        Ok(self)
    }
}
```

For maximal speed, add specialized tuple impls:

```rust
impl<A> IntoParams for (A,)
where
    A: Into<Value>,
{
    fn into_params(self, expected: usize) -> Result<Params> {
        if expected != 1 {
            return Err(Error::range(format!(
                "expected {expected} parameters, got 1"
            )));
        }

        let mut values = SmallVec::<[Value; 8]>::new();
        values.push(self.0.into());
        Ok(Params { values })
    }
}

impl<A, B> IntoParams for (A, B)
where
    A: Into<Value>,
    B: Into<Value>,
{
    fn into_params(self, expected: usize) -> Result<Params> {
        if expected != 2 {
            return Err(Error::range(format!(
                "expected {expected} parameters, got 2"
            )));
        }

        let mut values = SmallVec::<[Value; 8]>::new();
        values.push(self.0.into());
        values.push(self.1.into());
        Ok(Params { values })
    }
}
```

# 6. Error model

```rust
        self.extended_code

        Self::new(ErrorCode::Range, message)
```

# 7. Engine registry and one-owner-process rule

Your roadmap says one owner process per database directory. Phase 7 should enforce that.

## 7.1 Why registry is needed

This is dangerous:

```rust
let db1 = Database::open("app.rdb")?;
let db2 = Database::open("app.rdb")?;
```

If `db1` and `db2` create independent engines in the same process, you have split-brain buffer pools, WAL writers, checkpoints, and page caches.

Correct behavior:

```text
same canonical path in same process:
  attach to existing Arc<EngineInner>

same path in different process:
  fail unless server/wire mode is used
```

## 7.2 Implementation sketch

```rust
use std::{
    collections::HashMap,
    path::PathBuf,
    sync::{Arc, Mutex, OnceLock, Weak},
};

pub struct EngineRegistry {
    engines: Mutex<HashMap<PathBuf, Weak<EngineInner>>>,
}

impl EngineRegistry {
    pub fn global() -> &'static EngineRegistry {
        static REGISTRY: OnceLock<EngineRegistry> = OnceLock::new();
        REGISTRY.get_or_init(|| EngineRegistry {
            engines: Mutex::new(HashMap::new()),
        })
    }

    pub fn open_or_attach(&self, path: PathBuf, opts: OpenOptions) -> Result<Database> {
        let mut guard = self.engines.lock().unwrap();

        if let Some(existing) = guard.get(&path).and_then(Weak::upgrade) {
            existing.validate_compatible_open_options(&opts)?;
            return Ok(Database { inner: existing });
        }

        let process_lock = ProcessDbLock::acquire(&path, opts.read_only)?;
        let engine = Arc::new(EngineInner::open(path.clone(), opts, process_lock)?);

        guard.insert(path, Arc::downgrade(&engine));

        Ok(Database { inner: engine })
    }
}
```

`ProcessDbLock` should use platform file locking or a robust lockfile. This is not a hot path. Use a small cross-platform Rust wrapper or implement platform-specific locking behind one internal module.

# 8. Statement cache

Use two levels:

```text
Engine shared plan cache:
  key: normalized_sql + schema_version + prepare_flags
  value: Arc<PreparedInner>
  sharded locks
  prevents repeated parse/bind/plan across connections

Connection local cache:
  tiny LRU
  no cross-thread contention
  fastest path for repeated SQL on same connection
```

## 8.1 Cache key

```rust
#[derive(Debug, Clone, Hash, PartialEq, Eq)]
pub struct PlanCacheKey {
    normalized_sql_hash: u64,
    schema_version: u64,
    flags: PrepareFlags,
}
```

Do not key only by raw SQL if you support prepare flags, schema versions, or parameter-sensitive planning.

## 8.2 Shared plan cache

```rust
pub struct SharedPlanCache {
    shards: Box<[parking_lot::Mutex<PlanShard>]>,
}

struct PlanShard {
    map: hashbrown::HashMap<PlanCacheKey, Arc<PreparedInner>>,
    lru: lru::LruCache<PlanCacheKey, ()>,
}

impl SharedPlanCache {
    pub fn get(&self, key: &PlanCacheKey) -> Option<Arc<PreparedInner>> {
        let shard = self.shard(key);
        let mut guard = shard.lock();
        let value = guard.map.get(key).cloned();
        if value.is_some() {
            guard.lru.promote(key);
        }
        value
    }

    pub fn insert(&self, key: PlanCacheKey, prepared: Arc<PreparedInner>) {
        let shard = self.shard(&key);
        let mut guard = shard.lock();

        guard.map.insert(key.clone(), prepared);
        guard.lru.put(key, ());

        while guard.map.len() > MAX_PLANS_PER_SHARD {
            if let Some((old_key, _)) = guard.lru.pop_lru() {
                guard.map.remove(&old_key);
            } else {
                break;
            }
        }
    }

    fn shard(&self, key: &PlanCacheKey) -> &parking_lot::Mutex<PlanShard> {
        let h = key.normalized_sql_hash as usize;
        &self.shards[h & (self.shards.len() - 1)]
    }
}
```

For high-concurrency prepare storms, add a “singleflight” state:

```rust
enum CacheEntry {
    Ready(Arc<PreparedInner>),
    Preparing(Arc<PrepareWaiter>),
}
```

Only one thread compiles a missing plan; others wait.

# 9. Schema invalidation

Every prepared statement stores the schema version it was prepared against.

```rust
impl EngineInner {
    fn start_statement(
        &self,
        session: &mut Session,
        prepared: &Prepared,
        params: Params,
        interrupt: &AtomicBool,
        busy: &BusyPolicy,
    ) -> Result<CursorState> {
        let current_schema = self.catalog_schema_version();

        if prepared.schema_version() != current_schema {
            return self.reprepare_and_start(session, prepared, params, interrupt, busy);
        }

        self.sql_runtime.start(session, prepared, params, interrupt, busy)
    }

    fn reprepare_and_start(
        &self,
        session: &mut Session,
        old: &Prepared,
        params: Params,
        interrupt: &AtomicBool,
        busy: &BusyPolicy,
    ) -> Result<CursorState> {
        let mut attempts = 0;

        loop {
            attempts += 1;

            let fresh = self.prepare_shared(old.sql(), old.inner.flags)?;

            match self.sql_runtime.start(session, &fresh, params.clone(), interrupt, busy) {
                Ok(cursor) => return Ok(cursor),
                Err(e) if e.code() == ErrorCode::Schema && attempts < 4 => continue,
                Err(e) => return Err(e),
            }
        }
    }
}
```

For RedlineDB’s API, automatic reprepare should be implemented for cached statements. For C ABI, `rdb_step()` should also attempt a bounded reprepare for statements prepared through `rdb_prepare_v2`, matching the practical ergonomics users expect from SQLite-style APIs.

# 10. Busy handling and cancellation

Do not spin in the API layer.

```rust
pub enum BusyPolicy {
    NoWait,
    Timeout(std::time::Duration),
    Callback(Arc<dyn BusyCallback>),
}

pub trait BusyCallback: Send + Sync + 'static {
    fn call(&self, event: BusyEvent) -> BusyAction;
}

pub struct BusyEvent {
    pub attempt: u32,
    pub elapsed: std::time::Duration,
    pub reason: BusyReason,
}

pub enum BusyReason {
    RowLock,
    KeyLock,
    Checkpoint,
    Schema,
    CommitQueue,
}

pub enum BusyAction {
    Retry,
    Abort,
}
```

Rules:

```text
Never call a busy callback while holding a page latch.
Never call a C callback while holding a kernel latch.
Never hold a page latch during WAL fsync.
Never hold a page latch while waiting for another transaction.
```

Cancellation:

```rust
pub struct InterruptHandle {
    flag: Arc<AtomicBool>,
}

impl InterruptHandle {
    pub fn interrupt(&self) {
        self.flag.store(true, Ordering::Release);
    }
}
```

Executor checks:

```rust
if interrupt.load(Ordering::Acquire) {
    return Err(Error::new(ErrorCode::Interrupt, "operation interrupted"));
}
```

Check at:

```text
operator loop boundaries
lock wait boundaries
sort/hash build chunks
range scan page boundaries
long expression evaluation loops
backup step loops
```

# 11. Rust API optimized bulk paths

SQLite-style APIs are required, but RedlineDB should also expose Rust-native fast paths.

## 11.1 Prepared insert batch

```rust
pub struct PreparedBatch<'conn> {
    conn: &'conn mut Connection,
    prepared: Prepared,
    batch: Vec<Params>,
    max_rows: usize,
}

impl Connection {
    pub fn batch<'a>(&'a mut self, prepared: &Prepared) -> PreparedBatch<'a> {
        PreparedBatch {
            conn: self,
            prepared: prepared.clone(),
            batch: Vec::with_capacity(1024),
            max_rows: 1024,
        }
    }
}

impl<'conn> PreparedBatch<'conn> {
    pub fn push(&mut self, params: impl IntoParams) -> Result<()> {
        let p = params.into_params(self.prepared.parameter_count())?;
        self.batch.push(p);

        if self.batch.len() >= self.max_rows {
            self.flush()?;
        }

        Ok(())
    }

    pub fn flush(&mut self) -> Result<()> {
        if self.batch.is_empty() {
            return Ok(());
        }

        self.conn.db.inner.execute_batch(
            &mut self.conn.session,
            &self.prepared,
            &self.batch,
        )?;

        self.batch.clear();
        Ok(())
    }
}
```

This lets Rust applications do:

```rust
let insert = db.prepare("INSERT INTO events(ts, user_id, payload) VALUES (?, ?, ?)")?;

conn.transaction(|tx| {
    let mut batch = tx.batch(&insert);

    for event in events {
        batch.push(params![event.ts, event.user_id, event.payload])?;
    }

    batch.flush()
})?;
```

The SQL path stays correct, but the executor can amortize:

```text
parameter decoding
constraint setup
index lookup setup
row encoder allocation
WAL reservation
```

## 11.2 Typed table appender

A Rust-only API can later bypass SQL parsing for bulk inserts while still using the same catalog, constraints, indexes, and WAL machinery:

```rust
let mut appender = conn.appender("events", &["ts", "user_id", "payload"])?;

appender.push((ts, user_id, payload))?;
appender.flush()?;
```

This should be additive, not a substitute for SQL.

```rust
    cell::UnsafeCell,
    ffi::CString,
    os::raw::{c_char, c_int, c_void},

    cell: ConnCell,

// - Serialized is safe for concurrent C calls.
// - NoMutex is only safe if the caller does not use the same handle concurrently.

unsafe impl Sync for ConnCell {}

unsafe impl Sync for StmtCell {}

    code: ErrorCode,
    extended_code: i32,
    message: CString,

impl Default for LastError {
    fn default() -> Self {
        Self {
            code: ErrorCode::Ok,
            extended_code: 0,
            message: CString::new("not an error").unwrap(),

}
```

```rust
impl RdbOpenOptions {
    unsafe fn to_rust_options(ptr: *const RdbOpenOptions, flags: c_int) -> Result<OpenOptions> {
        let mut opts = OpenOptions::new();

        opts.create_if_missing = flags & RDB_OPEN_CREATE != 0;
        opts.read_only = flags & RDB_OPEN_READONLY != 0;
```

## 12.5 FFI guard

No panic should cross the C ABI.

```rust
fn ffi_guard_with_conn<F>(db: *mut rdb, f: F) -> c_int
where
    F: FnOnce(&Arc<ConnHandle>) -> Result<c_int>,
{
    let result = catch_unwind(AssertUnwindSafe(|| {
        let conn = unsafe { conn_arc_from_raw_borrowed(db)? };
        f(&conn)
    }));

    match result {
        Ok(Ok(code)) => code,
        Ok(Err(err)) => unsafe {
            set_error_on_raw_conn(db, &err);
            err.code() as c_int
        },
        Err(_) => unsafe {
            set_error_on_raw_conn(
                db,
                &Error::new(ErrorCode::Internal, "panic crossed RedlineDB FFI boundary"),
            );
            RDB_INTERNAL
        },
    }
}
```

Borrowing an `Arc` from a raw pointer without decrementing it:

```rust
unsafe fn conn_arc_from_raw_borrowed(db: *mut rdb) -> Result<Arc<ConnHandle>> {
    if db.is_null() {
        return Err(Error::misuse("null database handle"));
    }

    let ptr = db as *const ConnHandle;

    Arc::increment_strong_count(ptr);
    let arc = Arc::from_raw(ptr);

    if arc.magic.load(Ordering::Acquire) != CONN_MAGIC {
        return Err(Error::misuse("invalid database handle"));
    }

    Ok(arc)
}
```

## 12.6 `rdb_open_v2`

```rust
#[no_mangle]
pub unsafe extern "C" fn rdb_open_v2(
    filename: *const c_char,
    out_db: *mut *mut rdb,
    flags: c_int,
    options: *const RdbOpenOptions,
) -> c_int {
    let result = catch_unwind(AssertUnwindSafe(|| -> Result<c_int> {
        if out_db.is_null() {
            return Err(Error::misuse("null out_db pointer"));
        }

        *out_db = ptr::null_mut();

        if filename.is_null() {
            return Err(Error::misuse("null filename pointer"));
        }

        let path = std::ffi::CStr::from_ptr(filename)
            .to_str()
            .map_err(|_| Error::new(ErrorCode::Misuse, "filename is not valid UTF-8"))?;

        let opts = RdbOpenOptions::to_rust_options(options, flags)?;
        let db = Database::open_with_options(path, opts)?;
        let conn = db.connect()?;

        let cell = if flags & RDB_OPEN_NOMUTEX != 0 {
            ConnCell::NoMutex(UnsafeCell::new(conn))
        } else {
            ConnCell::Serialized(parking_lot::Mutex::new(conn))
        };

        let handle = Arc::new(ConnHandle {
            magic: AtomicU64::new(CONN_MAGIC),
            cell,
            last_error: parking_lot::Mutex::new(LastError::default()),
            flags: flags as u32,
        });

        *out_db = Arc::into_raw(handle) as *mut rdb;

        Ok(RDB_OK)
    }));

    match result {
        Ok(Ok(code)) => code,
        Ok(Err(_err)) => {
            if !out_db.is_null() {
                unsafe {
                    *out_db = ptr::null_mut();
                }
            }
            RDB_CANTOPEN
        }
        Err(_) => RDB_INTERNAL,
    }
}
```

## 12.7 `rdb_close`

```rust
#[no_mangle]
pub unsafe extern "C" fn rdb_close(db: *mut rdb) -> c_int {
    if db.is_null() {
        return RDB_OK;
    }

    let ptr = db as *const ConnHandle;
    let arc = std::mem::ManuallyDrop::new(Arc::from_raw(ptr));

    if arc.magic.load(Ordering::Acquire) != CONN_MAGIC {
        return RDB_MISUSE;
    }

    if Arc::strong_count(&arc) > 1 {
        set_error(
            &arc,
            &Error::new(
                ErrorCode::Busy,
                "cannot close database while statements or backups are alive",
            ),
        );
        return RDB_BUSY;
    }

    arc.magic.store(0, Ordering::Release);

    let arc = std::mem::ManuallyDrop::into_inner(arc);
    drop(arc);

    RDB_OK
}
```

## 12.8 `rdb_prepare_v2`

SQLite-style prepare compiles one statement and returns a tail pointer. SQLite recommends the v2/v3 prepare family over legacy prepare APIs. ([SQLite][1])

```rust
#[no_mangle]
pub unsafe extern "C" fn rdb_prepare_v2(
    db: *mut rdb,
    sql: *const c_char,
    n_byte: c_int,
    out_stmt: *mut *mut rdb_stmt,
    tail: *mut *const c_char,
) -> c_int {
    ffi_guard_with_conn(db, |conn_handle| {
        if out_stmt.is_null() {
            return Err(Error::misuse("null out_stmt pointer"));
        }

        *out_stmt = ptr::null_mut();

        if !tail.is_null() {
            *tail = ptr::null();
        }

        if sql.is_null() {
            return Err(Error::misuse("null SQL pointer"));
        }

        let sql_bytes = read_c_sql_bytes(sql, n_byte)?;
        let sql_str = std::str::from_utf8(sql_bytes)
            .map_err(|_| Error::new(ErrorCode::Misuse, "SQL is not valid UTF-8"))?;

        let mut consumed = 0usize;

        let prepared = with_conn_mut(conn_handle, |conn| {
            let parsed = conn.db.inner.prepare_first_statement(sql_str)?;
            consumed = parsed.consumed_bytes;
            Ok(parsed.prepared)
        })?;

        if !tail.is_null() {
            *tail = sql.add(consumed);
        }

        let stmt = CStatement::new(prepared);

        let stmt_cell = if conn_handle.flags & (RDB_OPEN_NOMUTEX as u32) != 0 {
            StmtCell::NoMutex(UnsafeCell::new(stmt))
        } else {
            StmtCell::Serialized(parking_lot::Mutex::new(stmt))
        };

        let handle = Box::new(StmtHandle {
            magic: AtomicU64::new(STMT_MAGIC),
            conn: Arc::clone(conn_handle),
            stmt: stmt_cell,
            last_row: parking_lot::Mutex::new(CRowScratch::new()),
        });

        *out_stmt = Box::into_raw(handle) as *mut rdb_stmt;

        Ok(RDB_OK)
    })
}
```

Helper:

```rust
unsafe fn read_c_sql_bytes<'a>(ptr: *const c_char, n_byte: c_int) -> Result<&'a [u8]> {
    if n_byte < 0 {
        Ok(std::ffi::CStr::from_ptr(ptr).to_bytes())
    } else {
        let bytes = std::slice::from_raw_parts(ptr as *const u8, n_byte as usize);
        let nul_pos = bytes.iter().position(|b| *b == 0).unwrap_or(bytes.len());
        Ok(&bytes[..nul_pos])
    }
}
```

## 12.9 Bind functions

```rust
#[no_mangle]

    value: f64,
) -> c_int {
    ffi_guard_with_stmt(stmt, |stmt_handle| {
        with_stmt_mut(stmt_handle, |s| {
            s.bind(index, Value::Real(value))?;
            Ok(RDB_OK)
        })
    })
}

#[no_mangle]
pub unsafe extern "C" fn rdb_bind_null(stmt: *mut rdb_stmt, index: c_int) -> c_int {
    ffi_guard_with_stmt(stmt, |stmt_handle| {
        with_stmt_mut(stmt_handle, |s| {
            s.bind(index, Value::Null)?;
            Ok(RDB_OK)
        })
    })
}

#[no_mangle]
pub unsafe extern "C" fn rdb_bind_text(
    stmt: *mut rdb_stmt,
    index: c_int,
    text: *const c_char,
    n_byte: c_int,
) -> c_int {
    ffi_guard_with_stmt(stmt, |stmt_handle| {
        with_stmt_mut(stmt_handle, |s| {
            if text.is_null() {
                s.bind(index, Value::Null)?;
                return Ok(RDB_OK);
            }

            let bytes = read_c_sql_bytes(text, n_byte)?;
            let value = std::str::from_utf8(bytes)
                .map_err(|_| Error::new(ErrorCode::Mismatch, "text is not valid UTF-8"))?;

            // Copy at bind time for safety.
            s.bind(index, Value::Text(Arc::<str>::from(value)))?;

            Ok(RDB_OK)
        })
    })
}

#[no_mangle]
pub unsafe extern "C" fn rdb_bind_blob(
    stmt: *mut rdb_stmt,
    index: c_int,
    blob: *const c_void,
    n_byte: c_int,
) -> c_int {
    ffi_guard_with_stmt(stmt, |stmt_handle| {
        with_stmt_mut(stmt_handle, |s| {
            if blob.is_null() {
                s.bind(index, Value::Null)?;
                return Ok(RDB_OK);
            }

            if n_byte < 0 {
                return Err(Error::range("negative blob length"));
            }

            let bytes = std::slice::from_raw_parts(blob as *const u8, n_byte as usize);

            // Copy at bind time for safety.
            s.bind(index, Value::Blob(Bytes::copy_from_slice(bytes)))?;

            Ok(RDB_OK)
        })
    })
}
```

Use 1-based parameter indexes in the C ABI:

```rust
impl CStatement {
    fn bind(&mut self, one_based_index: c_int, value: Value) -> Result<()> {
        if one_based_index <= 0 {
            return Err(Error::range("parameter index is out of range"));
        }

        let idx = one_based_index as usize - 1;

        if idx >= self.bindings.len() {
            return Err(Error::range("parameter index is out of range"));
        }

        self.bindings[idx] = value;
        self.needs_reset_after_bind = true;

        Ok(())
    }
}
```

## 12.10 `rdb_step`

```rust
#[no_mangle]
pub unsafe extern "C" fn rdb_step(stmt: *mut rdb_stmt) -> c_int {
    ffi_guard_with_stmt(stmt, |stmt_handle| {
        let conn = Arc::clone(&stmt_handle.conn);

        with_stmt_mut(stmt_handle, |s| {
            with_conn_mut(&conn, |conn| {
                match s.step(conn)? {
                    CStep::Row(row) => {
                        let mut scratch = stmt_handle.last_row.lock();
                        scratch.capture(row);
                        Ok(RDB_ROW)
                    }
                    CStep::Done(done) => {
                        s.last_done = done;
                        Ok(RDB_DONE)
                    }
                }
            })
        })
    })
}
```

`CStatement`:

```rust
struct CStatement {
    prepared: Prepared,
    bindings: Vec<Value>,
    rows: Option<RowsOwned>,
    state: CStatementState,
    last_done: Done,
    needs_reset_after_bind: bool,
}

enum CStatementState {
    Ready,
    Running,
    Done,
    Error,
}

enum CStep {
    Row(RowBuffer),
    Done(Done),
}

impl CStatement {
    fn new(prepared: Prepared) -> Self {
        let parameter_count = prepared.parameter_count();

        Self {
            prepared,
            bindings: vec![Value::Null; parameter_count],
            rows: None,
            state: CStatementState::Ready,
            last_done: Done::default(),
            needs_reset_after_bind: false,
        }
    }

    fn step(&mut self, conn: &mut Connection) -> Result<CStep> {
        match self.state {
            CStatementState::Ready => {
                let params = Params {
                    values: SmallVec::from_vec(self.bindings.clone()),
                };

                self.rows = Some(conn.query_prepared_owned(&self.prepared, params)?);
                self.state = CStatementState::Running;
            }
            CStatementState::Running => {}
            CStatementState::Done => {
                return Err(Error::misuse("statement has finished; call reset before stepping again"));
            }
            CStatementState::Error => {
                return Err(Error::misuse("statement is in error state; call reset"));
            }
        }

        let rows = self.rows.as_mut().unwrap();

        match rows.step_owned()? {
            OwnedStep::Row(row) => Ok(CStep::Row(row)),
            OwnedStep::Done(done) => {
                self.rows = None;
                self.state = CStatementState::Done;
                Ok(CStep::Done(done))
            }
        }
    }

    fn reset(&mut self) -> Result<()> {
        self.rows = None;
        self.state = CStatementState::Ready;
        self.needs_reset_after_bind = false;
        Ok(())
    }

    fn clear_bindings(&mut self) {
        for b in &mut self.bindings {
            *b = Value::Null;
        }
    }
}
```

The C-owned statement uses an owned cursor form because it cannot rely on Rust borrow lifetimes. The internal implementation can still avoid per-row allocation by reusing buffers.

## 12.11 Column access

```rust
pub const RDB_NULL: c_int = 0;
pub const RDB_INTEGER: c_int = 1;
pub const RDB_REAL: c_int = 2;
pub const RDB_TEXT: c_int = 3;
pub const RDB_BLOB: c_int = 4;

#[no_mangle]
pub unsafe extern "C" fn rdb_column_count(stmt: *mut rdb_stmt) -> c_int {
    if stmt.is_null() {
        return 0;
    }

    let handle = &*(stmt as *mut StmtHandle);

    if handle.magic.load(Ordering::Acquire) != STMT_MAGIC {
        return 0;
    }

    with_stmt_ref_noerr(handle, |s| s.prepared.column_count() as c_int).unwrap_or(0)
}

#[no_mangle]
pub unsafe extern "C" fn rdb_column_type(stmt: *mut rdb_stmt, col: c_int) -> c_int {
    if stmt.is_null() || col < 0 {
        return RDB_NULL;
    }

    let handle = &*(stmt as *mut StmtHandle);
    let scratch = handle.last_row.lock();

    match scratch.value_ref(col as usize) {
        Some(ValueRef::Null) => RDB_NULL,
        Some(ValueRef::Integer(_)) => RDB_INTEGER,
        Some(ValueRef::Real(_)) => RDB_REAL,
        Some(ValueRef::Text(_)) => RDB_TEXT,
        Some(ValueRef::Blob(_)) => RDB_BLOB,
        None => RDB_NULL,
    }
}

#[no_mangle]
pub unsafe extern "C" fn rdb_column_int64(stmt: *mut rdb_stmt, col: c_int) -> i64 {
    if stmt.is_null() || col < 0 {
        return 0;
    }

    let handle = &*(stmt as *mut StmtHandle);
    let scratch = handle.last_row.lock();

    scratch
        .value_ref(col as usize)
        .and_then(|v| v.as_i64().ok())
        .unwrap_or(0)
}

#[no_mangle]
pub unsafe extern "C" fn rdb_column_bytes(stmt: *mut rdb_stmt, col: c_int) -> c_int {
    if stmt.is_null() || col < 0 {
        return 0;
    }

    let handle = &*(stmt as *mut StmtHandle);
    let scratch = handle.last_row.lock();

    scratch.bytes_len(col as usize).unwrap_or(0) as c_int
}

#[no_mangle]
pub unsafe extern "C" fn rdb_column_text(stmt: *mut rdb_stmt, col: c_int) -> *const c_char {
    if stmt.is_null() || col < 0 {
        return ptr::null();
    }

    let handle = &*(stmt as *mut StmtHandle);
    let mut scratch = handle.last_row.lock();

    scratch.column_text_cstr(col as usize)
}

#[no_mangle]
pub unsafe extern "C" fn rdb_column_blob(stmt: *mut rdb_stmt, col: c_int) -> *const c_void {
    if stmt.is_null() || col < 0 {
        return ptr::null();
    }

    let handle = &*(stmt as *mut StmtHandle);
    let scratch = handle.last_row.lock();

    scratch
        .column_blob_ptr(col as usize)
        .unwrap_or(ptr::null()) as *const c_void
}
```

For performance, provide a RedlineDB-specific no-copy text API:

```c
const unsigned char *rdb_column_text_ptr(
    rdb_stmt *stmt,
    int col,
    int *out_len
);
```

Unlike `rdb_column_text`, this does not need to create a NUL-terminated scratch string.

```rust
        })
    })

#[no_mangle]
pub unsafe extern "C" fn rdb_finalize(stmt: *mut rdb_stmt) -> c_int {
    if stmt.is_null() {
        return RDB_OK;
    }

    let handle = Box::from_raw(stmt as *mut StmtHandle);

    if handle.magic.load(Ordering::Acquire) != STMT_MAGIC {
        return RDB_MISUSE;
    }

    handle.magic.store(0, Ordering::Release);

    // Drops:
    // - statement
    // - row scratch
    // - Arc<ConnHandle>
    drop(handle);

    RDB_OK
}
```

## 12.13 Error access

```rust
static BAD_DB_HANDLE: &[u8] = b"bad database handle\0";

#[no_mangle]
pub unsafe extern "C" fn rdb_errcode(db: *mut rdb) -> c_int {
    if db.is_null() {
        return RDB_MISUSE;
    }

    let handle = &*(db as *mut ConnHandle);

    if handle.magic.load(Ordering::Acquire) != CONN_MAGIC {
        return RDB_MISUSE;
    }

    handle.last_error.lock().code as c_int
}

#[no_mangle]
pub unsafe extern "C" fn rdb_extended_errcode(db: *mut rdb) -> c_int {
    if db.is_null() {
        return RDB_MISUSE;
    }

    let handle = &*(db as *mut ConnHandle);

    if handle.magic.load(Ordering::Acquire) != CONN_MAGIC {
        return RDB_MISUSE;
    }

    handle.last_error.lock().extended_code
}

#[no_mangle]
pub unsafe extern "C" fn rdb_errmsg(db: *mut rdb) -> *const c_char {
    if db.is_null() {
        return BAD_DB_HANDLE.as_ptr() as *const c_char;
    }

    let handle = &*(db as *mut ConnHandle);

    if handle.magic.load(Ordering::Acquire) != CONN_MAGIC {
        return BAD_DB_HANDLE.as_ptr() as *const c_char;
    }

    handle.last_error.lock().message.as_ptr()
}

fn set_error(conn: &ConnHandle, err: &Error) {
    let msg = CString::new(err.message())
        .unwrap_or_else(|_| CString::new("error message contained interior nul").unwrap());

    let mut guard = conn.last_error.lock();
    guard.code = err.code();
    guard.extended_code = err.extended_code();
    guard.message = msg;
}
```

# 14. C API example

```c
#include "redlinedb.h"
#include <stdio.h>

int main(void) {
    rdb *db = NULL;

    RdbOpenOptions opts = {0};
    opts.struct_size = sizeof(RdbOpenOptions);
    opts.durability = RDB_DURABILITY_STRICT;
    opts.cache_bytes = 256ULL * 1024ULL * 1024ULL;
    opts.busy_timeout_ms = 5000;

    int rc = rdb_open_v2(
        "app.rdb",
        &db,
        RDB_OPEN_READWRITE | RDB_OPEN_CREATE | RDB_OPEN_NOMUTEX,
        &opts
    );

    if (rc != RDB_OK) {
        fprintf(stderr, "open failed\n");
        return 1;
    }

    rc = rdb_exec(
        db,
        "CREATE TABLE IF NOT EXISTS users(id INTEGER PRIMARY KEY, name TEXT)",
        NULL,
        NULL,
        NULL
    );

    if (rc != RDB_OK) {
        fprintf(stderr, "exec failed: %s\n", rdb_errmsg(db));
        rdb_close(db);
        return 1;
    }

    rdb_stmt *stmt = NULL;

    rc = rdb_prepare_v2(
        db,
        "INSERT INTO users(id, name) VALUES (?, ?)",
        -1,
        &stmt,
        NULL
    );

    if (rc != RDB_OK) {
        fprintf(stderr, "prepare failed: %s\n", rdb_errmsg(db));
        rdb_close(db);
        return 1;
    }

    for (long long i = 0; i < 10000; i++) {
        char name[64];
        snprintf(name, sizeof(name), "user-%lld", i);

        rdb_bind_int64(stmt, 1, i);
        rdb_bind_text(stmt, 2, name, -1);

        rc = rdb_step(stmt);

        if (rc != RDB_DONE) {
            fprintf(stderr, "step failed: %s\n", rdb_errmsg(db));
            break;
        }

        rdb_reset(stmt);
        rdb_clear_bindings(stmt);
    }

    rdb_finalize(stmt);
    rdb_close(db);

    return 0;
}
```

```rust
pub struct CliSession {
    db: Database,
    conn: Connection,
    output: OutputMode,
    headers: bool,
    timer: bool,
}

impl CliSession {
    pub fn run_line(&mut self, line: &str) -> Result<()> {
        if line.trim_start().starts_with('.') {
            return self.run_meta_command(line);
        }

        self.run_sql(line)
    }

    fn run_sql(&mut self, sql: &str) -> Result<()> {
        let started = std::time::Instant::now();

        let prepared = self.conn.prepare_cached(sql)?;

        if prepared.column_count() == 0 {
            let done = self.conn.execute_prepared(&prepared, ())?;
            println!("{} rows changed", done.rows_changed);
        } else {
            let mut rows = self.conn.query_prepared(&prepared, ())?;
            let mut printer = RowPrinter::new(self.output, self.headers, &prepared);

            while let Some(row) = rows.next()? {
                printer.row(row)?;
            }

            printer.finish()?;
        }

        if self.timer {
            eprintln!("elapsed: {:?}", started.elapsed());
        }

        Ok(())
    }
}
```

## 15.5 Import

Do not load the CSV into memory. Stream it.

```rust
fn import_csv(
    conn: &mut Connection,
    table: &str,
    columns: &[String],
    input: impl std::io::Read,
) -> Result<ImportStats> {
    let placeholders = std::iter::repeat("?")
        .take(columns.len())
        .collect::<Vec<_>>()
        .join(", ");

    let sql = format!(
        "INSERT INTO {table} ({}) VALUES ({placeholders})",
        columns.join(", ")
    );

    let prepared = conn.prepare_cached(&sql)?;

    let mut reader = csv::Reader::from_reader(input);
    let mut rows = 0_u64;

    conn.transaction(|tx| {
        let mut batch = tx.batch(&prepared);

        for record in reader.records() {
            let record = record.map_err(|e| Error::new(ErrorCode::Error, e.to_string()))?;

            let mut params = Params::new();
            for field in record.iter() {
                params.push(field);
            }

            batch.push(params)?;
            rows += 1;
        }

        batch.flush()
    })?;

    Ok(ImportStats { rows })
}
```

## 15.6 Smoke benchmark command

This is not Phase 9 certification. It is an API sanity check.

```rust
pub struct SmokeBenchConfig {
    pub connections: usize,
    pub rows_per_connection: usize,
    pub durability: Durability,
    pub batch_size: usize,
}

pub struct SmokeBenchResult {
    pub total_rows: u64,
    pub elapsed: std::time::Duration,
    pub rows_per_sec: f64,
    pub p50_commit_us: u64,
    pub p95_commit_us: u64,
    pub p99_commit_us: u64,
    pub wal_bytes: u64,
    pub peak_cache_bytes: u64,
}

pub fn run_smoke_bench(db: Database, cfg: SmokeBenchConfig) -> Result<SmokeBenchResult> {
    let insert = db.prepare("INSERT INTO bench(k, v) VALUES (?, ?)")?;

    let started = std::time::Instant::now();

    std::thread::scope(|scope| {
        for thread_id in 0..cfg.connections {
            let db = db.clone();
            let insert = insert.clone();

            scope.spawn(move || -> Result<()> {
                let mut conn = db.connect()?;

                conn.transaction(|tx| {
                    let mut batch = tx.batch(&insert);

                    for i in 0..cfg.rows_per_connection {
                        let k = ((thread_id as i64) << 48) | i as i64;
                        batch.push(params![k, format!("value-{k}")])?;
                    }

                    batch.flush()
                })
            });
        }

        Ok::<_, Error>(())
    })?;

    let elapsed = started.elapsed();
    let stats = db.stats();

    Ok(SmokeBenchResult {
        total_rows: (cfg.connections * cfg.rows_per_connection) as u64,
        elapsed,
        rows_per_sec: (cfg.connections * cfg.rows_per_connection) as f64
            / elapsed.as_secs_f64(),
        p50_commit_us: stats.commit_latency.p50_us,
        p95_commit_us: stats.commit_latency.p95_us,
        p99_commit_us: stats.commit_latency.p99_us,
        wal_bytes: stats.wal.bytes_written,
        peak_cache_bytes: stats.memory.peak_cache_bytes,
    })
}
```

## 16.5 Why not make core async?

Because embedded database operations are not naturally async at the operator level:

```text
buffer pool lookup
row lock wait
WAL append
fsync
page decode
B-tree traversal
hash aggregate
sort
```

Adding async all the way down usually adds overhead and complexity. Keep the core synchronous and make the server adapt it.

# 17. Threading rules for performance

## 17.1 Rust API

```text
Database:
  Clone + Send + Sync

Prepared:
  Clone + Send + Sync

Connection:
  Send + !Sync

Rows:
  !Send
  borrows one mutable Connection

Transaction:
  !Send
  borrows one mutable Connection
```

This means:

```rust
let db = Database::open("app.rdb")?;
let prepared = db.prepare("INSERT INTO t VALUES (?)")?;

std::thread::scope(|s| {
    for tid in 0..32 {
        let db = db.clone();
        let prepared = prepared.clone();

        s.spawn(move || {
            let mut conn = db.connect().unwrap();

            for i in 0..100_000 {
                conn.execute_prepared(&prepared, params![i]).unwrap();
            }
        });
    }
});
```

No global API mutex.

## 17.2 C ABI

Offer two modes:

```text
RDB_OPEN_NOMUTEX:
  fastest
  caller must not use same rdb* or rdb_stmt* concurrently

RDB_OPEN_FULLMUTEX:
  safer
  per-handle locking
  still no global database writer lock
```

Even in FULLMUTEX mode, the mutex is per connection/statement handle, not per engine.

## 17.3 Do not call user callbacks under locks

This includes:

```text
busy callbacks
trace callbacks
progress callbacks
commit hooks
rollback hooks
authorizer callbacks
custom scalar functions
custom collations
```

The safe rule:

```text
Release kernel latches first.
Release cache shard locks first.
Release WAL queue locks first.
Then call user code.
```

For custom SQL functions, the executor should call the user function outside page latches. The function may run while the statement is active, but it must not hold low-level storage latches.

# 18. Memory strategy

## 18.1 Avoid allocations on `step`

A prepared statement execution should allocate during:

```text
prepare
first execution setup
sort/hash operators if needed
large result materialization if unavoidable
```

It should not allocate for every simple row.

Fast path target:

```text
SELECT integer_col, text_col FROM indexed_table WHERE id = ?
  prepare: allocates
  bind: maybe allocates for text/blob params
  step row: no heap allocation for fixed-size columns
  column_int64: no allocation
  column_text_ptr_len: no allocation
  reset: no allocation
```

## 18.2 Use scratch buffers

Per connection:

```rust
pub struct ConnectionScratch {
    params: SmallVec<[Value; 8]>,
    expr_stack: Vec<Value>,
    encode_buf: Vec<u8>,
}
```

Per statement:

```rust
pub struct StatementScratch {
    row: RowBuffer,
    c_text_cache: Vec<Option<CString>>,
    converted_values: Vec<Option<Value>>,
}
```

## 18.3 C text behavior

`rdb_column_text()` may need NUL-terminated memory. That can force a copy. To avoid copies for performance-sensitive users, add:

```c
const unsigned char *rdb_column_text_ptr_len(
    rdb_stmt *stmt,
    int col,
    int *out_len
);
```

Then:

```text
rdb_column_text:
  returns NUL-terminated scratch
  may allocate/copy

rdb_column_text_ptr_len:
  returns raw pointer + length
  no NUL guarantee
  can be zero-copy
```

## 18.4 Large blobs

Do not force large blobs into memory for every caller. Add an incremental blob API later:

```c
int rdb_blob_open(...);
int rdb_blob_read(...);
int rdb_blob_write(...);
int rdb_blob_close(...);
```

Rust side:

```rust
pub struct BlobReader<'conn> {
    conn: &'conn mut Connection,
    handle: BlobHandle,
}
```

For Phase 7 initial release, regular column blobs can work, but the API should leave room for streaming blobs.

```rust
    pub fn execute(&mut self, sql: &str, params: impl IntoParams) -> Result<Done> {
```

# 22. API-level backup

Rust ergonomic API:

```rust
let mut backup = db.backup_to(
    "backup.rdb",
    BackupOptions {
        page_batch_size: 1024,
        include_wal: true,
        sync_on_finish: true,
    },
)?;

loop {
    match backup.step(1024)? {
        BackupStep::More {
            remaining_pages,
            total_pages,
        } => {
            eprintln!("backup: {remaining_pages}/{total_pages} pages remaining");
        }
        BackupStep::Done => break,
    }
}

backup.finish()?;
```

Backup invariants:

```text
backup sees a transactionally consistent snapshot
backup registers retention horizon
checkpoint/vacuum cannot remove pages/WAL needed by active backup
writers continue normally
backup copies in bounded page batches
backup has explicit finish/drop behavior
```

# 23. Extension points

## 23.1 Rust scalar functions

```rust
pub struct FunctionOptions {
    pub deterministic: bool,
    pub innocuous: bool,
    pub direct_only: bool,
}

pub trait ScalarFunction: Send + Sync + 'static {
    fn call(&self, args: &[ValueRef<'_>]) -> Result<Value>;
}

impl<F> ScalarFunction for F
where
    F: Send + Sync + 'static + Fn(&[ValueRef<'_>]) -> Result<Value>,
{
    fn call(&self, args: &[ValueRef<'_>]) -> Result<Value> {
        self(args)
    }
}

impl Connection {
    pub fn create_scalar_function(
        &mut self,
        name: &str,
        arity: FunctionArity,
        options: FunctionOptions,
        function: impl ScalarFunction,
    ) -> Result<()> {
        self.db.inner.register_scalar_function(
            &mut self.session,
            name,
            arity,
            options,
            Arc::new(function),
        )
    }
}
```

## 23.2 Collations

```rust
pub trait Collation: Send + Sync + 'static {
    fn compare(&self, left: &str, right: &str) -> std::cmp::Ordering;
}

impl Connection {
    pub fn create_collation(
        &mut self,
        name: &str,
        collation: impl Collation,
    ) -> Result<()> {
        self.db.inner.register_collation(name, Arc::new(collation))
    }
}
```

For C ABI, delay complex UDF/collation callbacks until the basic ABI is stable. They are easy to expose unsafely and hard to change later.

# 26. Performance gates for Phase 7

These gates measure API overhead, not full SQL competitiveness.

## 26.1 No accidental serialization

Run:

```text
N threads
N connections
same prepared INSERT
disjoint keys
single explicit transaction per thread
```

Gate:

```text
throughput increases as N increases until WAL/device/CPU conflict
no flatline caused by API mutex
no single global prepare/step lock
```

## 26.2 Prepared statement fast path

Gate:

```text
prepare once
execute 1,000,000 times
no SQL parse after first prepare
no schema lookup lock on every step except cheap atomic schema version check
```

## 26.3 C ABI overhead

Compare:

```text
Rust execute_prepared loop
C rdb_bind/rdb_step/rdb_reset loop
```

Gate:

```text
C ABI overhead is measurable but small
C NOMUTEX faster than FULLMUTEX
Rust API remains fastest
```

## 26.4 Memory ceiling

Run:

```text
many connections
many prepared statements
streaming SELECT of large table
slow C column consumer
```

Gate:

```text
statement cache respects configured capacity
row buffers reuse memory
large result sets stream
current-row pins do not grow unbounded
```

## 26.5 CLI must not distort benchmarks

CLI smoke benchmark should report:

```text
connections
rows
duration
throughput
p50/p95/p99 commit latency
WAL bytes
fsync count
checkpoint count
peak cache bytes
```

But formal SQLite head-to-head belongs to Phase 9.

# 28. The key “brilliant simplicity” decisions

The simplest high-performance architecture is:

```text
One engine per database directory per process.
Many independent connections per engine.
Prepared plans are immutable and shareable.
Connections are Send but not Sync.
Rust API uses lifetimes instead of locks.
C ABI uses opaque handles and optional per-handle mutexes.
No global writer mutex.
No async in the embedded core.
No page latches held across user callbacks or column access.
Rows stream.
Statement memory is reused.
C strings are copied only when needed.
Server is an adapter, not the core.
```

That keeps Phase 7 fast, stable, and extensible without compromising RedlineDB’s larger goal: SQLite-like ergonomics with a concurrency model that does **not** inherit SQLite’s single-writer ceiling.
