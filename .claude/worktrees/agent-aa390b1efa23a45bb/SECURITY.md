# Security Policy

If you find a security issue in RedlineDB, report it privately rather than opening a public issue.

Preferred reporting paths:

- GitHub Security Advisories, if enabled for this repository
- any private maintainer contact listed in repository settings

Please include:

- a short description of the issue
- impact and exploitability
- affected versions or commit range
- a minimal reproduction if available

Do not disclose the issue publicly until a fix is available.
