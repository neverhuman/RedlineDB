# Provenance

The authoritative development source for this repository and all split members
is local Jeryu. Release evidence is generated from:

- `repos.manifest.toml`
- `VERSION`
- `CHANGELOG.md`
- `RELEASE_PROCESS.md`
- `ROLLBACK.md`
- `.jankurai/repo-score.json`
- `.jankurai/repo-score.md`

The CI bare-mirror cache is derived from local Jeryu tags during validation and
is not a source of release truth.
